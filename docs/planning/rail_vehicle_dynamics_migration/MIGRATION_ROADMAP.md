# 轨道车辆动力学迁移与重构路书

本文件是 OpenRailVehicleDynamics 现行唯一的车辆动力学实施路书。它把阶段一的前半段
「GZ18 被动纵切」拆成 6 个子目标、9 个原子 Goal。每次 Goal 模式只执行其中一个 Goal；
不得在执行过程中重新规划整条路线或顺手扩展范围。

「为什么这样决定」记在 [DISCUSSION_AND_DECISION_LOG.md](DISCUSSION_AND_DECISION_LOG.md)，
只读事实与开放问题记在 [MIGRATION_OBSERVATIONS.md](MIGRATION_OBSERVATIONS.md)。本文件只回答
「做什么、按什么顺序、怎么算完成」，不重复裁决理由。

## 不再讨论的前提

以下条目已在裁决账本中收口，实施期不重新审议。括号内为账本编号。

- 产品动力学路径只支持 C++；不迁移、不兼容 `pydrake`。Python 只能进入默认不构建、不安装的
  科研实验层。（PREF-001、PREF-023、DEC-013）
- 阶段一先 GZ18、后 IRW，两车通过共同被动纵切才算阶段一闭环。**本路书只覆盖 GZ18 部分**，
  G55 完成不等于阶段一闭环。（DEC-008）
- 主积分路径是 CVODE BDF 加逐次右端状态求值。采样保持与 Radau3 是阶段二两个正交能力，
  不阻塞被动纵切。（PREF-002、DEC-009）
- 不迁移 WRL 的通用静平衡与 PRELOAD 求解器。首版只加载「60 km/h 已解析移动启动状态」，
  其他速度（含零速）在没有对应已解析身份时早拒绝。该状态不得称为「60 km/h PRELOAD」。
  （PREF-005、PREF-006、PREF-017、DEC-007）
- 车辆必须从无线路超高、无轨道不平顺的直线段启动；沿运行方向，缓和曲线起点与不平顺淡入起点
  都必须严格位于首轴初始里程之后，否则在建模或初始化阶段明确报错。（PREF-016、DEC-006）
- 轮轨算法采用近期固化的共同主体：共同法向接触角、三维互穿长度、无形状修正、自然三次型面、
  局部接触半径参考速度、二次泊松比 Kalker 系数表、Kalker 1982 自适应网格。自旋蠕滑率照常计算
  并参与 FASTSIM 切向应力，只把**直接接触斑蠕滑矩**规定为 `Mz = 0`。`pk_beta` 与
  `sqrt(Reff·pen)` 明确淘汰，且不得作为结构体兜底默认残留。（PREF-003、DEC-005、OBS-017）
- 开发期保留受控低层策略以复现两车各自的 WRL 行为：车轮型面预处理，以及型面/轨道侧滚 y-z 输运。

## Goal 模式规则

每个 Goal 必须满足以下格式：

```text
Goal GNN — <明确的功能名称>

前置 Goal：
唯一产物：
允许修改：
明确不做：

完成门：
1. <可执行、可判定>
2. <可执行、可判定>
3. <可选第三项>
```

执行纪律：

1. 一个 Goal 只产生一个逻辑产物；直接测试和必要说明随产物一起完成。
2. 在 `main` 上连续推进，一 Goal 一个聚焦提交；不建分支，不 push。
3. 每次开始前读取本路书中的 Goal 定义和直接前置产物，不重新审议已定路线。
4. 完成门全部通过才标记完成；失败就在当前 Goal 内修复，不用兼容层绕过。
5. 只为真实可达的失败模式或廉价的非法输入保留反例；不要求每条完成门配反例，也不把故意破坏
   产品源码、测试之测试或极端数值边界做成常驻门。
6. 若发现必须改变已接受架构，停止当前 Goal，先单独形成明确的新决策。
7. 构建产物、日志、临时观测、性能输出、金标和哈希不进入 Git；一次性探针用完即删。

**完成门的判别力要求。** 结构计数和总质量等检查可以抓到漏装、重复装配或占位体被误删，但不单独
承担跨实现忠实性证明。每个 Goal 还须至少有一项解析关系、几何/物理不变量或事务性质门。跨实现宏观比较只在仓外
临时运行，不将数据与结果带回主线。

## 与初始五 Goal 提案的差异

本草案把最初提出的五个 Goal 重排为九个。该重排已经接受，差异与理由逐条如下。

| # | 初始提案 | 本草案 | 理由 |
|---|---|---|---|
| 1 | 首个 Goal 同时产出 JSON 基础、目录结构、惯性系约定、GZ18 拓扑、启动状态 | 拆为 G47/G48/G49/G51 四个 | 五个并列逻辑产物违反「一 Goal 一逻辑产物」；且严格 JSON 捆绑第三方依赖原子准入，依赖准入必须独立成 Goal |
| 2 | 惯性系约定放在首个 Goal | 放在 G47，产物为轨道几何库 | 惯性系若只写进配置而无计算消费者，「以真实消费者校验抽象」不成立。轨道位姿是它的第一个真实消费者 |
| 3 | 启动状态与启动域早拒绝分属两个 Goal | 合并进 G51 | 验证器与被验证对象分属两 Goal 时，前一个 Goal 交付不出可执行完成门 |
| 4 | 启动状态先于轨道几何 | 轨道几何先于启动状态 | 启动位形的装配公式逐体消费轨道位姿与中心线求值，依赖方向与初始顺序相反 |
| 5 | 横移/摇头观测放在轨道几何 Goal | 站位投影原语放 G47；迁移期观测放 G55 | 投影是轨道几何逆操作；观测与采样历史只有端到端消费者，不提前形成公开 API |
| 6 | 复合状态与力元同一个 Goal | 保持同一 Goal（G50） | 拆开会让状态块扩展缺少真实消费者。此条与初始提案一致，特此确认 |
| 7 | 串行接触主链与两套低层策略同一个 Goal | 拆为 G52/G53 | 「接触核心落地」与「接入右端求值」是两个逻辑产物；策略绑定随核心走 |

## 子目标 18：建立线路与轨道设施基础

- [x] **G47 — 建立线路惯性系与轨道几何**
  - **前置 Goal**：无（消费 G01–G46 底座）
  - **唯一产物**：模型中立的 `libs/track_geometry`：线路惯性系、直线／Hermite 缓和／圆曲线、
    平面里程中心线、纵坡、超高、C² 接缝过渡、轨型系位姿与一阶运动学，以及局部站位投影。
    参数由类型化 C++ 值构造，不读文件。
  - **允许修改**：新建 `libs/track_geometry/`；根 `CMakeLists.txt` 的产品模块清单、安装目标与
    公共头安装循环；`tests/track_geometry/`、`tests/CMakeLists.txt` 与安装后消费者。
  - **明确不做**：不引入任何新第三方依赖；不读 JSON 或任何文件；不接多体、不接接触；
    不实现轨道不平顺、轨距加宽、轨底坡、钢轨型面倾角或公开输出合同；不接收站位速度、步长等
    历史提示，预测种子由 G54 上层计算。

  **坐标与量义。** 惯性系 `I`：`+x` 沿起点里程增加方向，`+y` 向右，`+z` 向下。
  `track_station` 是平面投影里程，故 `‖d[x,y]/ds‖=1`；`centerline_upward_grade>0` 表示上坡，
  `dz_I/ds=-grade`。无侧滚系 `T₀` 的 `x` 轴沿三维单位切向，`y` 向右，`z=x×y`。
  超高 `u=(p_right-p_left)·z_T₀`，`φ=asin(u/b_ref)`，`R_IT=R_IT₀·R_x(φ)`。
  后续装配器显式设置 `g_I=[0,0,+g]`，多体底座保持坐标中立。

  **几何与数值。** 缓和曲线采用曲率的 Hermite 三次混合，**不是回旋线**。无接缝的相邻剖面
  必须端值连续；声明的接缝窗口用匹配两端值、一阶导与二阶导的五次多项式。直线和圆曲线解析
  积分，缓和与接缝采用固定阶确定性求积；节点间距是显式精度参数。构造期允许分配，成功求值
  路径不扩容动态容器、不查名称、不写日志、不访问文件。位姿与一阶运动学同次返回，并满足
  `dR_IT/ds=[ω_IT]×R_IT`；中心线二阶导保持私有。

  - **完成门**：
    1. 圆曲线闭式位置与曲率、Hermite 内部点、接缝 C²、求积收敛、左右曲线镜像、定义域与超高
       约束均通过；解析、求积和有限差分分别使用对应容差。
    2. 非零曲率／航向／纵坡／超高夹具的 `R_IT` 九分量、正交性、行列式、超高符号和旋转率恒等式
       通过。
    3. 中心线竖向导数及轨型系纵轴竖向分量与正负纵坡的数值关系通过。
    4. 站位投影只做无历史的**局部分支跟踪**：窗口在节点分辨率下必须恰有一个严格内点极小根，
       且满足 `F'=0` 的残差门与 `F''>0`。窗口壁根不计入候选；没有唯一严格内点根或参数非法时
       失败。不提供全线搜索，同一节点区间内未被网格分开的多根不在完备性承诺内。

  说明：WRL 侧存在切向系 `z` 分量取 `-sinθ`、而中心线导数取 `+slope` 的符号不一致，因其四个
  内置预设纵坡恒为零而长期休眠；本 Goal 按上述坐标约定裁决，不沿用该休眠状态。WRL 源全局系
  与 `I` 逐轴同义，`diag(1,-1,-1)` 仅是其 Drake 世界系转换；产品不保留运行期外部坐标转换层。

  - **实测收口**：模块已安装导出，只公开依赖 Eigen；五个公共头均有自包含编译门，安装消费者
    能链接并求值。圆弧积分采用避免近数相减的半角形式，节点位置使用补偿累加。三个聚焦测试覆盖
    上述四门；dev 38/38、release 38/38、drake-reference 42/42 通过，未新增告警。

- [ ] **G50 — 接通复合连续状态与 GZ18 车辆力元**
  - **前置 Goal**：G49
  - **唯一产物**：把系统连续状态从固定的 `[q; v]` 两块扩展为**有序状态块列表** `[q; v; z…]`，
    并落地 GZ18 的第一方车辆力元族与类型化力元计划，使 `z` 有真实消费者。
  - **允许修改**：`libs/system_assembly`（描述、实例、编译计划）；`libs/integrators` 的 RHS 桥与
    接受事务；新建 `libs/forces`（复用现有空壳目录）；`libs/configuration/` 与
    `vehicle_library/gz18/` 增加力元定义；必要时扩展 `libs/multibody_model` 的力元入口；根
    `CMakeLists.txt`；`tests/system_assembly/`、新建 `tests/forces/`、`tests/integrators/`。

    弹簧—阻尼（GZ18 通道数为零，无真实消费者）；不接接触；不开启调用期外力入口。

  力元族按真实本构命名，不按厂商或车型命名。GZ18 实际生效的力元为四类：代数平动弹簧—阻尼、
  代数侧滚弹簧—阻尼力偶、**串联弹簧—黏性阻尼（有内部连续状态）**、非线性限幅阻尼（分段线性
  力律加端点饱和，无内部状态）。源模型中的四个零刚度牵引杆不含物理信息，GZ18 产品记录直接
  省略，不建立“登记后丢弃”的占位路径。

  平动力元的完整扳手语义同样属于产品合同，不是诊断选项：相对位移和速度在**基准端标记系**
  表达，等大反向力分别施加于基准端与对端的真实标记原点；基准端另施加
  `τ_ref = (p_opposite − p_ref) × F_ref` 的组件支承矩，对端自由矩为零。不得把两端改到中点、
  半角系或省略支承矩，也不得把支承矩与端点 `r × F` 重复计算。侧滚元是基准端标记系 `x` 方向
  的**物理空间纯力偶**：线性侧滚坐标取相对旋转矩阵的 `(2,1)` 元素，角速度取基准端系下相对
  角速度的 `x` 分量；所得力矩已经是物理空间力矩，不再经过欧拉角广义力映射。两体承受等大反向
  力矩、平动力为零，不产生端点平移附加矩。

  串联弹簧—黏性本构 `dF/dt = K·v − (K/C)·F` 是 `z` 块存在的唯一理由。GZ18 有 2 个横向通道，
  故 `z` 维数为 2。该通道的时间常数在数十微秒量级，是显式的刚性通道，逐分量绝对容差必须为它
  单列，不与 `q`/`v` 共用。

  状态块的约束：块的数量与各块维数在最终化时确定，构造后无追加路径；系统实例唯一拥有全部块
  且相邻布局；`z` 不是刚体广义坐标，也不是缓存；公开状态提交一次原子覆盖时间与全部块，失败则
  全部丢弃。G54 的内部接受步提示历史另行拥有 candidate 事务，不把每个内部步误写成物理状态提交。

  力元计划按真实本构族保存冻结的类型化数组，使用预分配的扳手与状态导数缓冲，并以确定顺序在
  每次 RHS 中恰好计算一次各实例。此处不强制通用虚基类、`variant` 或“两趟遍历”实现，也不建端口图。
  每个力元的端点、刚度、阻尼、限幅曲线与本构语义属于 `VehicleDefinition` 的不可变定义；逐实例
  悬挂预载／标称力属于上下文局部的具名启动参数。G50 在最终化时为后者建立类型化参数槽，G51
  只负责在启动装配事务中填入，成功装配后在该次运行内只读；它们不进入 `[q;v;z]`、不固化进
  编译计划，也不能由环境变量覆盖。

  - **完成门**：
    1. 串联本构的解析预言机：单通道在常速激励下的一阶精确解
       `F(t) = C·v + (F₀ − C·v)·e^{−(K/C)t}` 与数值解在声明容差内一致；`v ≡ const` 时
       `F → C·v` 渐近；时间常数 `C/K` 由响应独立辨识。
       该门不引用任何 WRL 数值。
    2. 事务原子性：以非法完整状态驱动公开接受入口时，时间与全部块均不变；成功的公开提交只使
       各块各推进一个版本。以拒绝某个 `z` 片段的测试组件驱动入口，验证 `q/v` 不会部分写入。
    3. 完整扳手与功率：为每个平动力元族构造端点不重合、基准端转动且相对运动非零的夹具；两端
       扳手移到共同原点后合力、合矩为零，端点虚功等于本构功率。删除基准端支承矩或把力移到中点
       时夹具必须失败。侧滚纯力偶夹具验证零平动力、等大反向物理空间力矩及相对角速度功率。
    4. 储能与耗散：代数平动弹簧—阻尼（含预载的仿射势能）满足
       `P_absorbed = dU/dt + D`。侧滚线性空间本构中，几何角导数 `alpha_dot_geom` 与采用的
       `omega_x` 在有限姿态下不严格相同，因此准确边界为
       `P_absorbed = dU/dt + D + K·alpha·(omega_x − alpha_dot_geom)`；该有限姿态线性化余项必须
       单独重建，不得强行吸收到能量误差。串联弹簧—黏性元满足
       `P_absorbed = d(F²/(2K))/dt + F²/C`；无储能的限幅阻尼满足 `P_absorbed ≥ 0`。
       非线性限幅力律还须在原点、线性插值段、`±0.02 m/s` 边界和两端饱和区连续且满足奇函数性。
    5. 力元计划与参数所有权：每个真实实例在一次 RHS 中恰好消费一次；串联力元的状态导数由解析
       预言机覆盖。两个上下文写入不同预载后互不污染；编译计划和 `VehicleDefinition` 均不持有
       可变预载值。
    6. 一次性来源核对：用仓外临时脚本或审计程序核对车辆力元的实例、端点、本构参数、启动参数
       槽位、状态维数与本构选择均已 all-and-only 迁入；脚本和输出用后删除，不把源提交标识或
       数值清单变成产品门。

  - **前置 Goal**：G53

  接受步数值历史的定性：它不是物理连续状态，不能并入 `[q; v; z]`；它也不是缓存，不能因输入未变
  就复用、也不能在任意时刻重算。每份历史由按 `VehicleDefinition` 中唯一接触载体集合索引的
  `s_prev[]`、`s_dot_prev[]` 和一个全体共享的 `dt_prev` 组成；两向量必须与载体集合 all-and-only，
  不得误按左右车轮重复或漏项。运行时同时持有 `accepted` 与 `candidate` 两份窄历史：公开推进开始
  时复制前者到后者，本次内部步的 RHS 只读 `candidate`，试算路径在类型上不可写 `accepted`。

  每次 `CV_ONE_STEP` 成功返回后，系统层把后端端点 `(t_reached, x_reached)` 显式装入试算上下文，
  在端点重新计算站位投影和接触结果，再推进 `candidate`；不得把“最后一次 RHS 缓存”当作端点，
  因为 CVODE 不保证两者同刻。到公开目标后，时间、`[q;v;z]` 与提示历史一次提交。后端失败、端点
  重算失败或最终验证失败都保持 `accepted` 不变，并把后端／candidate 标记为需要显式同步。

  初始化及外部接受状态改变后执行一次全局提示播种；它是确定的初始化／重同步，不是可切换的冷启动
  人格。提示是带版本和明确失效语义的真实数值历史源，不继承 WRL “写后不要中间读取”的口头约定。

  后端提供单一的 `AdvanceOneInternalStepToward(stop)` 语义，返回预分配端点及
  `{step_begin, step_end, reached_stop}`；系统层负责循环和提示事务，数值后端不回调接触层。
  ADR-0003 同步修订，并收口可绕过逐步提示更新的生产批量推进入口；密集输出仍只在后端报告的
  最近连续区间内有效。

  - **完成门**：
    1. 事务原子性与隔离：以在指定内部步失败的测试后端驱动公开推进，验证已接受时间、全部状态块
       和提示均不变，后续推进在显式同步前被拒绝；成功推进只在公开目标处提交一次。
    2. 提示的同义性与分支连续性：预测种子的局部投影与以已知根为种子的局部投影得到同一根，

       隔离唯一局部根，并保持在 `s_prev + s_dot_prev·dt_prev` 预测的连续邻域内；删除

6. 轨型参考竖向偏移是普通、必填、带单位的已解析产品输入；模式不增加 `external`、`frozen`、来源
   哈希或证明字段。ORVD 首版不求解它。
7. G55 固定 `10 ms`；仓外同站位宏观门为横移 `1e-4 m`、摇头 `1e-4 rad`，不移时、不滤波、不
   去均值、不拟合。公开输出合同继续挂起。
8. 不建设常驻字段往返审计工具链。G49 允许仓外一次性脚本核对源字段、坐标和惯量转换，用后删除；
   历史 WRL SHA 和工件路径保留为规划考古，不成为产品运行身份或完成门。

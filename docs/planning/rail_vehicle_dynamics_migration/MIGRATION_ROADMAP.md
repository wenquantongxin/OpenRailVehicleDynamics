# 轨道车辆动力学迁移与重构路书

本文件是 OpenRailVehicleDynamics 现行唯一的车辆动力学实施路书。它把从 GZ18 首次短窗纵切、
GZ18 不平顺长窗、IRW 被动迁移，到 IRW 1 kHz 控制与最小产品闭包的主线拆成 15 个子目标、
35 个原子 Goal（G47–G81）。每次 Goal 模式只执行其中一个 Goal；不得在执行过程中重新规划
整条路线或顺手扩展范围。

本路书只约束本机、本地代码智能体的实施顺序与提交边界，不限制安装后的公开 C++ 接口如何被
科研用户组合、修改或扩展；软件使用与再分发边界由许可证政策单独规定。

「为什么这样决定」记在 [DISCUSSION_AND_DECISION_LOG.md](DISCUSSION_AND_DECISION_LOG.md)，
只读事实与开放问题记在 [MIGRATION_OBSERVATIONS.md](MIGRATION_OBSERVATIONS.md)。本文件只回答
「做什么、按什么顺序、怎么算完成」，不重复裁决理由。

## 不再讨论的前提

以下条目已在裁决账本中收口，实施期不重新审议。括号内为账本编号。

- 产品动力学路径只支持 C++；不迁移、不兼容 `pydrake`。Python 只能进入默认不构建、不安装的
  科研实验层。（PREF-001、PREF-023、DEC-013）
- 阶段一先 GZ18、后 IRW，两车通过共同被动纵切才算阶段一闭环。G55 只是 GZ18 首次 10 ms
  闭环；G56–G72 才补齐 GZ18 激励长窗和 IRW 两层被动工况。（DEC-008）
- 主积分路径是 CVODE BDF 加逐次右端状态求值。IRW 当前承重的 30 s 被动参考同样采用
  `rhs_state_eval`，每次 RHS 试算态重算接触；历史接触采样保持不是被动主线。周期保持只随
  G74 的 1 kHz PID 作为真实事件消费者进入。Radau3 是独立的可选第二后端，尚无产品实现来源
  裁决，不进入 G47–G81 的完成门。（PREF-002、DEC-009、OBS-023）
- 不迁移 WRL 的通用静平衡与 PRELOAD 求解器。随库资格化实例是「60 km/h 已解析移动启动状态」；
  用户可修改 `V0` 研究其他严格正向速度，轮速按既有启动等效滚动半径等比例变化；只有轮轨型面、
  接触策略、载荷工况或轨型偏移改变时才须同步更新该半径。零速与反向启动拒绝；近零速及随后
  跨零速的轮轨物理尚未资格化，首版不作有效性承诺。
  该状态不得称为「60 km/h PRELOAD」。
  （PREF-005、PREF-006、PREF-017、DEC-007）
- 随库 GZ18 示例从直线、水平、零超高且无不平顺的区段启动；通用科研入口允许非平直外推，
  但不自动继承参考工具对齐资格。（PREF-016、DEC-006）
- 轮轨算法采用近期固化的共同主体：共同法向接触角、三维互穿长度优先且解析弦长作基线、无形状修正、自然三次型面、
  局部接触半径参考速度、二次泊松比 Kalker 系数表、Kalker 1982 自适应网格。自旋蠕滑率照常计算
  并参与 FASTSIM 切向应力，只把**直接接触斑蠕滑矩**规定为 `Mz = 0`。`pk_beta` 与
  其他未选人格分支不迁入。解析弦长不是可选择的长度人格：它始终由当前几何量计算，三维长度解析成功
  才覆盖；解析失败时沿用基线并从同一次求值报告回退，不增加第二次状态求值、热路径日志、字符串格式化
  或动态分配。（PREF-003、DEC-005、OBS-017；项目负责人裁决，CodeX 记录，2026-08-08）
- 开发期保留受控低层策略以复现两车各自的 WRL 行为：车轮型面预处理，以及型面/轨道侧滚 y-z 输运。

## Goal 模式规则

每个 Goal 必须满足以下格式：

```text
Goal GNN — <明确的功能名称>

前置 Goal：
唯一产物：
允许修改：
明确不做：

完成门：
1. <可执行、可判定>
2. <可执行、可判定>
3. <可选第三项>
```

执行纪律：

1. 一个 Goal 只产生一个逻辑产物；直接测试和必要说明随产物一起完成。
2. 在 `main` 上连续推进，一 Goal 一个聚焦提交；不建分支，不 push。
   **G52 是项目负责人于 2026-08-05 给出的显式例外**：它拆成 G52a／G52b／G52c 三个强制审查子步，
   每个子步各自形成一个原子提交。每个子步必须依次完成：对该子步做两遍独立自检（第二遍不得只是
   重复第一遍的同一条命令）；只把该子步相关文件形成一个原子本地提交；随后**立即暂停**，不预写下一
   子步的产品代码，等阶段性对抗审查明确放行后才继续。该例外只适用于 G52，不推广到其他 Goal。
3. 每次开始前读取本路书中的 Goal 定义和直接前置产物，不重新审议已定路线。
4. 完成门全部通过才标记完成；失败就在当前 Goal 内修复，不用兼容层绕过。
5. 只为真实可达的失败模式或廉价的非法输入保留反例；不要求每条完成门配反例，也不把故意破坏
   产品源码、测试之测试或极端数值边界做成常驻门。
6. 若发现必须改变已接受架构，停止当前 Goal，先单独形成明确的新决策。
7. 构建产物、日志、临时观测、性能输出、金标和哈希不进入 Git；一次性探针用完即删。

**完成门的判别力要求。** 结构计数和总质量等检查可以抓到漏装、重复装配或占位体被误删，但不单独
承担跨实现忠实性证明。每个 Goal 还须至少有一项解析关系、几何/物理不变量或事务性质门。跨实现宏观比较只在仓外
临时运行，不将数据与结果带回主线。

## 子目标 18：建立线路与轨道设施基础

- [x] **G47 — 建立线路惯性系与轨道几何**
  - **前置 Goal**：无（消费 G01–G46 底座）
  - **唯一产物**：模型中立的 `libs/track_geometry`：线路惯性系、直线／Hermite 缓和／圆曲线、
    平面里程中心线、纵坡、超高、C² 接缝过渡、轨型系位姿与一阶运动学，以及局部站位投影。
    参数由类型化 C++ 值构造，不读文件。
  - **允许修改**：新建 `libs/track_geometry/`；根 `CMakeLists.txt` 的产品模块清单、安装目标与
    公共头安装循环；`tests/track_geometry/`、`tests/CMakeLists.txt` 与安装后消费者。
  - **明确不做**：不引入任何新第三方依赖；不读 JSON 或任何文件；不接多体、不接接触；
    不实现轨道不平顺、轨距加宽、轨底坡、钢轨型面倾角或公开输出合同；不接收运行期站位历史；
    局部分支种子由 G54 上层持有并逐接受端点更新。

  **坐标与量义。** 惯性系 `I`：`+x` 沿起点里程增加方向，`+y` 向右，`+z` 向下。
  `track_station` 是平面投影里程，故 `‖d[x,y]/ds‖=1`；`centerline_upward_grade>0` 表示上坡，
  `dz_I/ds=-grade`。无侧滚系 `T₀` 的 `x` 轴沿三维单位切向，`y` 向右，`z=x×y`。
  超高 `u=(p_right-p_left)·z_T₀`，`φ=asin(u/b_ref)`，`R_IT=R_IT₀·R_x(φ)`。
  后续装配器显式设置 `g_I=[0,0,+g]`，多体底座保持坐标中立。

  **几何与数值。** 缓和曲线采用曲率的 Hermite 三次混合，**不是回旋线**。无接缝的相邻剖面
  必须端值连续；声明的接缝窗口用匹配两端值、一阶导与二阶导的五次多项式。直线和圆曲线解析
  积分，缓和与接缝采用固定阶确定性求积；节点间距是显式精度参数。构造期允许分配，成功求值

  力元族按真实本构命名，不按厂商或车型命名。GZ18 实际生效的力元为四类：代数平动弹簧—阻尼、
  代数侧滚弹簧—阻尼力偶、**串联弹簧—黏性阻尼（有内部连续状态）**、非线性限幅阻尼（分段线性

  省略，不建立“登记后丢弃”的占位路径。

  平动力元的完整扳手语义同样属于产品合同，不是诊断选项：相对位移和速度在**基准端标记系**
  表达，等大反向力分别施加于基准端与对端的真实标记原点；基准端另施加
  `τ_ref = (p_opposite − p_ref) × F_ref` 的组件支承矩，对端自由矩为零。不得把两端改到中点、
  半角系或省略支承矩，也不得把支承矩与端点 `r × F` 重复计算。侧滚元是基准端标记系 `x` 方向
  的**物理空间纯力偶**：线性侧滚坐标取相对旋转矩阵的 `(2,1)` 元素，角速度取基准端系下相对
  角速度的 `x` 分量；所得力矩已经是物理空间力矩，不再经过欧拉角广义力映射。两体承受等大反向
  力矩、平动力为零，不产生端点平移附加矩。

  串联弹簧—黏性本构 `dF/dt = K·v − (K/C)·F` 是 `z` 块存在的唯一理由。GZ18 有 2 个横向通道，
  故 `z` 维数为 2。该通道的时间常数在数十微秒量级，是显式的刚性通道，逐分量绝对容差必须为它
  单列，不与 `q`/`v` 共用。

  状态块的约束：块的数量与各块维数在最终化时确定，构造后无追加路径；`SystemInstance` 冻结逻辑
  布局，每个 `SystemRuntimeContext` 唯一拥有自己的 q/v/z。q/v 仍由多体上下文持有，z 由根运行时
  上下文持有；只有复制给积分器时才形成逻辑连续向量，不为“相邻布局”复制第二份状态。`z` 不是刚体
  广义坐标，也不是缓存；公开状态提交一次原子覆盖时间与全部块，失败则全部丢弃。G54 的内部接受步
  提示历史另行拥有 candidate 事务，不把每个内部步误写成物理状态提交。

  力元计划按真实本构族保存冻结的类型化数组，使用预分配的扳手与状态导数缓冲，并以确定顺序在
  每次 RHS 中恰好计算一次各实例。此处不强制通用虚基类、`variant` 或“两趟遍历”实现，也不建端口图。
  每个力元的端点、刚度、阻尼、限幅曲线与本构语义属于装配前可修改、计划最终化时一次消费的
  `VehicleDefinition`；逐实例悬挂预载／标称力属于上下文局部的具名启动参数。G50 在最终化时为
  后者建立类型化参数槽，G51
  只负责在启动装配事务中填入，成功装配后在该次运行内只读；它们不进入 `[q;v;z]`、不固化进
  编译计划，也不能由环境变量覆盖。

    4. 储能与耗散：代数平动弹簧—阻尼（含预载的仿射势能）满足

       必须观察到同一预载。编译计划和 `VehicleDefinition` 均不持有可变预载值。
    6. 一次性来源核对：用仓外临时脚本或审计程序核对 28 个非零活动车辆力元的实例、端点、本构
       参数、启动参数槽位、状态维数与本构选择均已 all-and-only 迁入；同时明确核对并排除源中

       或数值清单变成产品门。

  **三维长度处置的最终合同（项目负责人裁决，CodeX 记录，2026-08-08）**：解析弦长
  `L_base = 2·sqrt(2·R_eff·penetration)` 是所有求值共有的基线，不是另一个可选人格；有限且为正的三维
  互穿长度解析成功后覆盖它，解析失败则保留 `L_base` 并在同一次结果中标明回退。近期 WRL 正式 RHS
  路径已经实际消费该语义：2026-08-02 的平顺 30 s 与 AAR5 30 s 工件分别记录 302/10,934,468 与
  4,686/23,936,829 次回退／尝试；计数包含重复 RHS 与被拒步试算，不得误称为唯一接受态样本。QCH
  没有公开三维长度不可解析时的处置，故本裁决是优先复现近期 WRL 执行语义，不宣称为 QCH 定义本身。
  可观测性只复用本次求值已有量并做定长标志／计数，不得为统计再求值、写热路径日志或分配存储。

  消费，文档不得称其「全局已死」；Kalker 权重非一与 `kMaxYZ`／`kMaxYN` 则没有任何人格选中，属可干净
  删除，删 `kMaxYZ`／`kMaxYN` 时应连同其无门控的生产循环一并去掉。

  自然三次样条／源横坐标重离散加分段线性），以及型面/轨道侧滚 y-z 输运的启用与否。GZ18 绑定前者的
  第一种与后者的关闭态。**互斥且不可叠加是就车轮型面预处理的两个分支而言**——两条轴本身是正交的，
  同时使用重离散与侧滚输运是合法组合。**不提供任意组合入口，不提供运行期切换。**

  要求在两车分阶段迁移期间保留这两处差异，因此“IRW 装配尚未进入 G47–G55”不等于其绑定归零。
  侧滚 y-z 输运的**纯数学与类型化策略属本 Goal**，其真实消费者是手工构造的完整刚体运动学输入；
  真实线路位姿的获取与开关判断归 G53，核心里不得保留无人读取的布尔字段。该输运的合同是**部分施加**：
  三个偏移只作用于位姿阶段与轨侧接触角，蠕滑输入与接触点约化仍使用原始横移／侧滚／摇头量。这个
  非对称必须由类型或注释明确归属，并由 G52a 的数学夹具直接判别——施加一个纯滚动偏移会改变法向方向
  与切向合力，而法向力大小不变。启用态与关闭态的判别力来自「偏移是否被算出并送入位姿」，不是核心内
  的一个布尔分支。本 Goal 的合成消费者只证明核心合同，不得据此宣称随包型面与真实轨道已经接通。
  待两车均落地且专项晋级裁决移除最后一个车型绑定时，同一次改动必须删除相应策略；某一维只剩一个
  策略时连同选择层一起折叠。WRL 提交与工件可作为该决策的历史证据保留，但不进入产品配置、运行时
  身份或完成门。

  **参数按五类承载，这也是完成门 4 的分母**：一、共性物理参数（弹性模量、泊松比、摩擦律常数）；
  二、车型策略位；三、显式离散参数（型面弧长采样点数、形心积分细分数、横向分箱宽度、
  斑合并间隙阈值、FASTSIM 网格划分数、接触判据裕度、FASTSIM 自适应网格容差、两个型面预处理步长）；
  四、实现内部常量（斑数与分段上界、求根迭代次数与容差、求积阶数），由解析性质或
  结构测试约束，不为凑齐清单升格成产品配置；五、**资产派生常量**——由型面、轨距、轨距测量深度与
  轨底坡派生的量（左右轨型横向基准即属此类），必须在加载型面后按同一派生函数重算，不得抄冻结字面量；
  该类进入完成门 4 分母的是**派生公式与其输入**，不是某一次求解出的数值。
  第一到第三类作为显式配置项承载，不作为算法常量硬编码；其取值随车型策略身份绑定。
  软极值温度不在此列——它唯一的消费者是本 Goal 明确不迁的软极值形心。
  轨距与轨距测量深度是接触型面装配输入，由本 Goal 类型化承载；线路的钢轨参考横距是线路参考几何，
  不得冒充轨距。

  **型面资产政策（项目负责人 2026-08-05 抉择）**：供应商 `.prw/.prr` 不进入 Git、不上传远端、不随
  安装包发布，只留在本地用于科研核对与向参考工具回灌验证。ORVD 随包发布**本项目自有、自包含、
  格式清晰的 JSON 型面资产**，它是运行时型面的唯一真源；项目不依赖 CONTACT，也不把其资产或代码
  引入依赖链。第一方型面设施须同时提供严格 JSON 读写、受支持的 `.prw/.prr` 读写，以及二者之间的
  **语义转换**；兼容通路服务本地开发与验证，不进入接触求值热路径，也不得成为第二份运行时权威。
  转换验证比较坐标系、单位、角色与点列语义，不要求注释、空白、头字段顺序或字节级往返；测试只用
  临时生成的合成文件，仓内不得提交供应商型面或由其直接生成的固化夹具。不固化型面哈希、外部绝对
  路径或供应商文件名为运行身份。参考实现「读取点列后静默忽略全部头部变换」的做法不得沿用：未查明
  或未支持的非恒等变换必须响亮拒绝。

  正式 JSON 必须显式携带**模式版本、型面角色、坐标轴与单位、有限且有序的点列**，按既有严格 JSON 纪律

  声明，输出采用参考工具可导入的规范简式。已知的两处形状事实必须被合同覆盖：其一，供应商轮型文件
  声明了一个非恒等的数据顺序标志，参考实现忽略它而未出错只是因为那些点在文件内本就按横坐标升序，
  ORVD 不得以此为由继续忽略；其二，轨型点列的横向步长并非严格常数，不得用「首点加等步长」的算式
  假装是均匀网格来做 O(1) 查表。**合成夹具证明不了兼容器能读真实文件**，因此本 Goal 须另做一次仓外
  一次性核对：用本地真实供应商文件走一遍读入与语义转换，只判定是否被正确接受与解释，程序、输入与
  输出用后删除，不进 Git、不进完成门、不留数值。

    不建立通用观察器、回调注册表或事件框架；不创建 `apps/`；不把任何轨迹、端点状态、步数或误差
    统计写入 Git；不声称阶段一闭环。

  本节按近期冻结 P035 的原生比较轴勘正早期 `0.01 m` 同站位口径：`10 ms` 短窗使用
  `k=0..100`、间隔 `0.1 ms` 的 101 个同时间序号样本；跨平台比较阶段禁止另作后处理插值或重采样。
  G49/G50 已覆盖的畸形记录、力元本构变异和合成观察器不在本 Goal 重复；本次勘正不改变 G54 的
  内部接受步或站位历史语义。

  G55 在已安装积分器模块增加一个窄公共 C++ 接口
  `AdvanceToWithDenseStateSamples(target_time_seconds, sample_times_seconds)`，按值返回
  `continuous_state_size() × sample_count` 的密集状态矩阵。它是公共 C++ API，但不是车辆级公开
  观测格式或稳定输出合同。样本时刻必须非空、有限且严格递增，首项逐位等于入口 accepted 时间，
  末项逐位等于推进目标；全部输入检查在进入后端前完成。单列只允许目标等于当前 accepted 时间，
  此时复制当前状态而不进入后端。首列逐位等于入口 accepted 状态，末列逐位等于最终 accepted 状态，
  中间列只从其所在成功内步的密集区间读取，不把采样时刻变成 CVODE 停靠点。一次调用的百万成功
  内步预算覆盖全部内部步。后端、密集读取、端点投影或最终提交任一失败时不返回矩阵，accepted 的
  时间、109 维状态和四项站位均保持不变，并进入 G54 已有的显式同步封锁态；输入预检拒绝不进入该状态。

  推进与密集状态批成功后，调用方才在独立私有上下文中组成迁移期观测批。内部观测包括四轴横移／
  摇头，以及八轮 `Q/N/Tx/Ty` 与接触斑数。横移定义为轮对原点相对投影站位处轨道中心线的局部
  `y` 分量；摇头取 `R_TB` 的 X–Z–Y 分解第二角。私有四项投影延续量由 G51 已解析四轴站位播种，
  随样本时间单调推进；它不进入 `[q;v;z]`、不反馈 RHS，也不覆盖 G54 的 accepted/candidate 历史。
  每个接口的接触观测与该样本扳手必须出自同一次真实接触结果，不另写第二套法向／切向力公式。
  任一投影或接触观测失败只丢弃整批观测和私有延续量，不撤销已经成功接受的 `10 ms` 端点或已经
  返回的密集状态批，也不使推进器进入同步封锁态。

  接触量沿用 G52 已定合同：SIMPACK Type-80 原生 `Tx/Ty` 是轨侧端点量，比较前取负成为规范轮侧
  分量；`N` 是正的局部法向力；`Q` 由完整轮侧力向 `−z_T` 投影，不得以 `N` 或 `N·cos(delta)` 代替；
  斑数直接读取真实 `WheelRailContactResult::count`，不得从合力是否非零推断。“禁止缩放”专指禁止
  结果相关的拟合缩放；声明的单位换算、坐标变换和端点符号转换是比较前的必需步骤，须逐项登记。

  仓外资格的三个主列分别为：P035 原生 SIMPACK binary32 工件；在当前 WRL 基线 `d7e272d` 上以
  P035 冻结物理输入、GZ18 v60 启动身份、当前接触人格、`stability_straight_2000m`，并显式外接
  全零横向／垂向不平顺数组、采用 `rhs_state_eval` 和固定步 Radau3 `100 µs` 重新运行的结果；ORVD
  G55 结果。不得把裸用该预设说成零不平顺：其自身还声明了尚未在本短窗激活的横向正弦。P035 结案时的
  `5df8c192` 干净基线加仓外归档研究补丁／构建只作历史控制列，不冒充当前 WRL 软件身份。三列按
  整数样本序号同时间配对，SIMPACK 时间只核序号身份，不要求与 binary64 逐位相同；跨平台比较不得
  另作后处理插值或重采样、移时、滤波、平滑、结果相关缩放、去均值，也不得改用 `0.01 m` 共同
  站位格。P034 静态偏移只可作为仓外生命周期历史反例，不进入产品输入、默认测试或金标。临时脚本、
  轨迹、统计与文件哈希用后删除。

  `Q/N/Tx/Ty` 的 `1 N / 1 N / 5 N / 5 N` 是在查看 ORVD G55 结果前，根据 P035 已观测差异量级
  新预登记的 G55 跨实现门；P035 文件中的 `1 N` 原为可见性阈值，并非这组完成门。Ty 的预算较紧，
  不描述成宽松预算。

  - **完成门**：
    1. 端到端、密集状态与观测分层：从车辆、启动和线路三类严格记录装配，并由已绑定启动身份解析
       两份随包型面 JSON；一次密集推进成功到达 `10 ms`，返回 `109 × 101`（88,072 B）有限状态矩阵，
       首末列与入口／最终 accepted 状态逐位相同。矩阵的一次局部分配允许发生在 RHS 外；右端热路径
       仍无动态分配。复用 G54 的真实线路边界失败时不得提交端点或返回状态批；随后对合法状态批组成
       观测，只有 101 点全部成功才发布观测批，观测失败不回滚推进。
    2. 启动支承、接触拓扑与直线段：`t=0` 八轮的真实 `result.count` 均为一个正载接触斑；每轮
       `Q` 与 G51 声明目标之差不超过 `1 N`，且目标值不作为外力施加。每个自由体初始惯性系竖向
       加速度满足 `|a_I,z| ≤ 1e-3 m/s²`。全 `10 ms` 八轮持续正载、单斑，并逐样本直接核对四个载体
       实际投影站位处曲率、超高和纵坡均为零；不得用场景名或“前 50 m”标签代替求值。不得把 P035
       已分栏的约 `60.8841 N` 纵向合力、`−0.01518 N·m` 俯仰矩、纵向加速度或转动响应误写成
       “六分量静力平衡”失败。
    3. `t=10 ms` 装配、切片与投影接线：在最终 accepted context 上恰好求值一次完整 109 维右端；
       另由现有类型化计划取得 56 个车辆扳手、8 个接触扳手与两个 Maxwell 导数。64 个空间扳手须先
       逐项断言 `expressed_in_frame == world_frame()`，再按真实作用点投影；所得广义力与
       `CalcRequiredGeneralizedForces(context, vdot)` 所需外加广义力闭合。由作用点速度独立重建的
       空间虚功与广义力对 `v` 的功率闭合。右端 `qdot` 逐项等于公开映射 `N(q)v`，尾部两个 `zdot`
       逐项等于车辆力计划写出的 Maxwell 导数。本门只验证动态端点的装配、固定切片与投影接线，
       不冒称本构独立预言机，不做源码变异或非物理扰动。
    4. 同时间仓外纵切：四个轮对分别对横移和摇头检查原始量误差及相对各平台自身 `t=0` 的增量误差，

       `Q/N/Tx/Ty` 的原始量及自身初值增量报告均方根和最大绝对误差；均方根不得省略或替代最大值，
       两种形式的最大值分别通过 `1 N / 1 N / 5 N / 5 N`。每轮逐时刻真实 `result.count` 均为一。

       仓内不复制 G49/G50 拒绝表，也不以源码变异或合成观察器再造测试之测试。

## G55 之后的共同资格纪律

G56–G81 的长窗、跨实现与产品化工作共同遵守以下纪律；各 Goal 不再重复展开：

1. **长窗不进默认 CTest。** 默认测试只保留短解析夹具、装配、事务、守恒与真实消费者烟测。
   完整物理长窗由 Linux Release 本地资格运行承担；GCC、Clang 和 Windows 只要求短真实消费者、
   安装迁移与运行期闭包，不建立平台×车型×线路×控制器的笛卡尔矩阵。
2. **仓库不保存长轨迹和数值金标。** 场景配方、类型化输入合同和解析性质可进 Git；WRL／SIMPACK
   轨迹、统计、性能日志和哈希均在仓外生成并用后删除。SHA 只可用于下载或搬运时的一次校验，
   不成为物理身份或完成门。
3. **动态响应默认按同站位比较。** G60 为复现既有 `10 s` 激活证据，显式例外地按共同整数时间索引
   且两端对应轴站位同时落入预登记窗口裁决；从 G61 起，每轴分别投影到预先声明的公共站位格，
   只在相邻样本间线性插值。不移时、不滤波、不去均值、不拟合、不缩放，也不用结果相关网格补救
   覆盖不足。
4. **只观察五层承重因果链。** 依次为输入身份／激活站位／采样时钟，接触斑与八轮三向力，
   四轴横移／摇头，代表性构架／车体响应与悬挂功率，最后是完整动力学残差／虚功／能量／耗散。
   只有某层首次出现持续差异时才展开该层内部通道，不复制 WRL 的大列宽诊断表。
5. **输入资产与基础线路正交。** 不平顺是独立站位场，不改写 `TrackGeometry` 中心线；大型横／垂
   数组独立于场景 JSON，启动时一次加载成不可变对象，RHS 不读文件、不解析 JSON、不重新生成随机谱。
6. **观测先保持内部。** G58 的长窗观测只服务迁移资格；坐标、单位、时钟、聚合和文件格式到
   G79 才冻结为公开合同。此前不得因临时 WRL 输出方便而反向塑造公共 API。

# ORVD 计算性能文档

本目录管理 ORVD 在**保持既有车辆动力学资格结论**前提下的计算性能工作。它与已经封存的
G01–G82 迁移路书分开：车辆能力是否存在由迁移路书回答，现有能力怎样减少墙钟、CPU 和内存开销
由本目录回答。

## 计时术语

- **动力学推进墙钟**：CVODE、车辆右端和接受态事务的墙钟时间。
- **观测墙钟**：在既有密集状态上重放车辆与轮轨观测的墙钟时间；归档样本不成为额外积分停靠点。
- **运行器分段总计**：推进、观测、端点诊断和工件写出的分段计时之和；不包含随后写性能摘要、
  发布目录以及进程启动／退出的尾部。
- **完整进程墙钟**：从外层包装器启动资格程序到其退出的实测墙钟；这是端到端实时系数的权威分母。
- **实时系数**：模拟时长除以墙钟时间。大于 `1` 表示平均吞吐快于实时，但不证明最坏时延或硬实时。

引用性能数字时必须说明工况、源码提交、Release 配置、线程数、CPU 亲和性和上述计时边界。短窗只
用于筛选与定位，不能线性外推为 `16/20/30 s` 长窗结果。

## 证据与提交纪律

1. 临时轨迹、性能摘要、剖析结果和试验脚本放在仓库 `tmp/` 或仓外临时目录，不进入 Git，也不作为
   产品输入、测试期望或永久金标。
2. 仓内只保存算法、解析误差界、接受／否决结论和可重算的证据入口；不固化某台机器的速度门或
   输出哈希。
3. 逐位等价优化必须保持物理观测、接触斑记录和积分统计完全一致。具有明确误差预算的优化必须
   重新运行 GZ18 与 IRW 的冻结长窗，并继续按现行 SIMPACK 口径观察；IRW 阈值是启动完整时序、
   模态、相位、峰值次序、包络、接触切换和最长零力复核的报警线，不由孤立峰值自动裁决。
4. 候选通过后直接替换唯一实现；候选失败则撤回，不在产品中留下兼容开关、旧算法分支或自由组合
   的性能旋钮。
5. 直接父提交不重新构建或运行，复用上一 Goal 留存的父工件和性能数据；本轮候选只在 Release、目标
   8 线程和固定 CPU 亲和性下运行两次，结果以算术平均和最小—最大范围报告。跨 Goal 比较不冒称同场
   配对，后台负载须如实记录；两次后仍无法区分收益与噪声时挂起或否决，不补第三次追逐最好值。

## 当前状态

专项分支已经完成 GZ18 存在性研究，但它在 IRW、100 Hz 控制和跨平台闭包进入主线之前分叉。
因此不合并整分支，也不机械摘取提交。PERF-01 基线、PERF-02 型面定位减算、PERF-03 精确接触缓存链、
PERF-05 车型中立并行稠密数值 Jacobian 和 PERF-06 基态精确缓存播种已收口；PERF-04 共同被动资格观测
并行经双车实测无稳定收益，已撤回。PERF-07 已完成逐位等价的横截面扫描减算；PERF-08 已以解析
`20 nm` 局部界、GZ18 数值门和 IRW 完整时序形状复核收口。IRW 在少数接触切换点超过原预登记的
逐点门，路书如实保留该边界，不把它改写成数值门通过。PERF-09 已以向上舍入的严格弦长上界筛除
无竞争站位；三条长窗相对 PERF-08 全工件逐字节不变，推进墙钟均稳定下降。当前进入将两个数值候选
分开资格化的 PERF-10。候选 A 已以中点偶次多项式归一化收口：GZ18 长窗逐位不变，IRW B/C 未触发
既有科学报警，三工况推进均取得约 `1.42–1.51×` 的跨 Goal 历史加速；候选 B 的 FASTSIM 平方判定
也已独立收口，三工况推进相对候选 A 再提高约 `1.06–1.09×`。候选 B 不冒称逐位等价：IRW 存在
毫秒级接触切换差异，P179 的 `24016` 个轮—事件限幅标志中有 `11` 个瞬时差异；负责人查看完整时序后
确认宏观模态、相位、峰值次序、长期接触与控制模式保持并予以接受。平方判定现为唯一实现，不留旧路径
或开关。实施状态、当前 Goal 与完成门只以
[双车型计算性能迁移路书](PERFORMANCE_MIGRATION_ROADMAP.md)为准。

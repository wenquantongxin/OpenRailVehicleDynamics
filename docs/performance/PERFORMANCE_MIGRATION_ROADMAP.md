# ORVD 双车型计算性能迁移路书

## 目标与状态

本路书把 `codex/gz18-performance` 已验证的算法候选重新落位到现行 `main`，并将公共部分下沉到
GZ18 与 IRW 共用的轮轨接触、系统右端和积分器。目标是在不改变既有物理资格结论的前提下降低
动力学推进和完整资格流水线墙钟。

- 路书状态：**PERF-01 至 PERF-12 已收口；PERF-04 候选已否决并撤回**
- 当前 Goal：**PERF-13 — 双车型长窗与跨平台收口**
- 来源分支：`codex/gz18-performance`
- 来源边界：`0b471a7778dd2fb320e15b286163750750a87685..73236dcf933654ff69cf720f8d1ecabb5275fad0`
- 目标分支：`main`

性能编号使用 `PERF-NN`，不重新打开已封存的 G01–G82。来源分支保持只读；每项在现行架构上重新
实现、验证并形成独立提交，不整分支合并，也不机械 `cherry-pick`。

## 不再讨论的原则

1. **通过即直接替换。** 通过精度与性能门的候选成为唯一实现，不保留旧路径、兼容开关、运行时
   策略枚举或实验环境变量。
2. **公共算法与车型配方分开。** 轮轨几何、接触缓存和按状态维数工作的 Jacobian 可以共用；容差、
   线性系统重组频率和观测布局先按车型资格，不由 GZ18 推导 IRW。
3. **逐位优化与数值优化分开提交。** 逐位优化不得改变物理输出或积分历史；具有明确误差预算的
   优化必须先写出解析界与预登记判据，再看车辆结果。
4. **不新增通用性能控制面。** 线程数仍由工作量、OpenMP 可用资源和私有上限解析；误差阈值与初筛
   次数保持内部常量。没有真实用户需求时不增加公共线程、缓存或积分器策略 API。
5. **不搬过时诊断。** 现行主线已有轻量积分统计和外层进程指标包装器；专项分支的 GZ18 专用阶段
   探针、大型误差向量和私有统计桥不进入产品。
6. **不以速度反推物理。** 不降低 FASTSIM `21×21` 网格，不缩窄真实运动范围，不拒绝可能出现的
   多斑或短暂失联，也不以更容易积分为理由改变车辆、线路或控制时相。
7. **允许合理的空间换时间。** 每个 Jacobian worker 可以长期持有完整独占工作上下文与轻量精确缓存；
   数百 MiB 的单模型峰值内存不因自身数值否决候选。只有持续增长、换页、内存不足或影响同机运行时
   才升级处理，不为节省几十或几百 MiB 引入共享池、锁或反复重建。

## PERF-03 起的代表资格矩阵

后续性能 Goal 只使用三个代表长窗：GZ18 一个，IRW 两个。它们分别覆盖刚性轮对、
独立旋转车轮的被动响应和 100 Hz 主动控制；已完成的其余科学工况不因此失效，但不在每个
性能候选上机械重跑。

| 车型 | 工况 | 时长 | 主要科学观察 |
|---|---|---:|---|
| GZ18 | 直线 AAR6 | `20 s` | 四轴横移／摇头，八轮 `Q/N/Tx/Ty`，不平顺全激励过程 |
| IRW B | R300+AAR5、被动 | `30 s` | AAR5 新增响应、八轮力和接触拓扑 |
| IRW C | P179、R300+AAR5、100 Hz 主动控制 | `30 s` | 宏观响应、八轮力、请求／实际／保持转矩、控制事件与限制状态 |

直接父提交不再重新构建或运行；每个 Goal 复用上一 Goal 留存的科学工件和性能数据。从 PERF-09 起，
每个新候选只使用 Release、目标 8 线程和固定 `8–15` CPU 亲和性，将下列三工况各运行恰好两次，
报告候选均值和范围，不补第三次，也不新增 1／4 线程专项矩阵；PERF-05 已签收的 1／4／8 常驻门由
完整 CTest 自然执行。跨 Goal 的父数据与本轮候选计时是历史基线比较，不冒称同场交错配对；后台
负载必须如实记载。两次候选仍无法与噪声分离时，候选挂起或否决。验证按候选性质分层：

- **逐位结构候选**：先以短真实消费者和常驻门证明逐位等价，再以三条代表长窗判定真实路径收益。
- **有误差预算候选**：三条代表长窗逐项通过后才可替换，因为局部舍入或几何误差可能沿车型和控制闭环放大。
- **车型积分配方**：GZ18 AAR6 与 IRW B／C 分别消融，不以一车结论代替另一车。

被动共同运行器的观测优化覆盖 GZ18 与 IRW A／B；P179 的事件运行器具有独立时相，除非剖析证明
观测仍是主要瓶颈，否则只自然消费公共接触与积分器优化，不在本轮重构其观察事务。

## 测量与精度协议

### 性能

- 使用同一 Release 配置、同一输入、相同线程预算和固定 CPU 亲和性；记录编译器、CPU、OpenMP
  环境、峰值内存及源码提交。
- 同时记录完整进程墙钟、运行器分段墙钟、成功内步、普通／线性 RHS、误差测试失败、非线性迭代／
  失败、线性 setup 和 Jacobian 次数。
- 不构建、不运行直接父提交；父科学与性能证据直接复用上一 Goal 的留存工件。本轮候选每个工况恰好
  运行两次，报告两次原值、均值和范围。跨 Goal 比较不是同场配对，须同时标明父、候选的计时来源及
  后台负载；两次后仍不能与噪声分离，则撤回或挂起，不再补第三次。
- 分别观察无激励、受激和完整窗口；不从车辆起步的快速段外推后段。
- 墙钟不进入 CTest，某台机器的绝对速度也不成为产品身份。

### 逐位等价候选

- 局部算术候选先以源码等价证明和紧凑性质门闭合正确性；代表长窗只负责确认真实路径消费及稳定
  收益，不用昂贵仿真重复证明同一个表达式。
- `observations.tsv`、`contact_patches.tsv` 及端点诊断的物理字段逐字节一致；忽略墙钟、线程数等
  执行元数据。
- P179 还要求 `control_events.tsv`、控制器状态、限制标志和保持转矩一致。
- CVODE 内步、普通／线性 RHS、Jacobian、setup、拒步和终步统计一致。
- 并行候选还须核对私有上下文所有权、投影历史、控制事件后的保持转矩同步、固定序发布和异常先于
  发布。PERF-05 已签收的 1／4／8 线程常驻回归继续保留；PERF-06 起的专项性能与资格只运行目标
  8 线程配置，不扩建线程矩阵。线程检查器只作竞态辅助，不能替代这些结果级证据。

任何一项不一致都说明候选不是逐位优化，不能靠放宽比较阈值继续本 Goal。

### 有误差预算候选

- 每个 Goal 在运行候选前，根据局部解析误差界和既有车辆资格限预登记允许的响应增量；不看完结果
  再选阈值。
- 候选与直接父基线在原生时序和各轴共同里程上比较横移、摇头、`Q/N/Tx/Ty`，同时看曲线、均方根、
  最大值、相位和局部峰值，不能只用均方根判定。
- `Q/N` 是每个轮轨接口对全部接触斑聚合后的总量；`Tx/Ty` 沿用既有迁移观察合同，在多斑时是
  主斑／既定观察量，不是接口切向合力。主斑切换产生的瞬时峰值必须结合逐斑记录和接触切换判断，
  不能误读为接口合力的不连续。
- 既有 ORVD—SIMPACK 宏观资格不得由通过变为失败，也不得出现一致性恶化的新相位或新峰值。
- 接触斑数和瞬时脱离作观察；持续零力、新增长时间失联或接触拓扑体制变化直接拒绝。
- IRW C 另核对控制事件序号、请求／调理／保持转矩、轮速和限制状态，不允许改变 100 Hz 时相。

IRW 的预登记数值阈值是报警线，不是脱离时序证据的自动生死门。报警后必须同时核对整段时序和里程
曲线的模态、相位、峰值次序、包络、相关性／最佳滞后、接触切换与最长零力时段；孤立点或毫秒级切换
差异不自动否决，也不得由实现者静默放宽或放行。整段曲线、模态、相位或长期接触体制发生变化时，
须上呈负责人裁决。逐位候选没有该放行路径：全序列必须零差、相关系数为 1、最佳滞后为 0，斑数序列
和最长零力区间完全一致。

### PERF-08 — 资格化 `20 nm` 三维纵向弦长误差合同

- **来源**：`7f29fef` 的纵向弦长终止部分。
- **唯一产物**：以前后根纵向坐标误差上界为终止条件的唯一弦长求解；36 次只作为不可收敛硬上限。
- **明确不做**：不以固定迭代次数冒充精度，不把误差阈值暴露到 JSON 或公共 API。
- **完成门**：由正弦函数的利普希茨界和运行时实际局部半径证明 `20 nm` 局部界；该证明不依赖
  LM 或 S1002 的型面曲率，无须为 IRW 重写第二套解析界。三条代表长窗仍须核对两种轮型真实消费、迭代
  次数、稳定收益，以及该局部误差经 EEC、轮轨力与主动控制的下游传播。

**候选运行前预登记的数学合同：**

固定一个横向站位，令运行时实际局部轮径为 `r_local`、轮对摇头角为 `yaw`，轮面点的纵向坐标为

```text
x(theta) = r_local * cos(yaw) * sin(theta)
p = abs(r_local * cos(yaw))
```

若一个连续符号根括区的角宽为 `Delta theta`，正弦函数的 `1-Lipschitz` 性给出：

1. 返回括区中点时，单根纵向坐标绝对误差不超过 `p * Delta theta / 2`；
2. 前、后根均在 `p * Delta theta <= 20 nm` 时返回，两根误差之和不超过 `20 nm`，因此所得纵向弦长
   的绝对误差不超过 `20 nm`；
3. 对所有横向站位取最大弦长时，`max` 对上确界范数同样为 `1-Lipschitz`，最终最长弦仍保持
   `20 nm` 绝对误差界；
4. `p` 必须由每个站位的运行时实际局部半径计算，不得以标称半径代替。证明只依赖连续符号括区，
   不依赖 LM 或 S1002 的型面曲率，双车共用同一公式。

36 次二分只保留为两份随包车型在铁路尺度内的硬上限。候选长窗前以正式型面的实际局部半径和最大
搜索括区做一次仓外短扫描，证明 36 次后 `p * Delta theta` 远低于 `20 nm`；不为恶意巨大半径增加

### PERF-10 — 分别资格化中点归一化与 FASTSIM 平方判定

- **来源**：`417b34b`。
- **唯一产物**：两个先后独立提交的数值候选，而不是一个混合性能包。
- **明确不做**：不修改 FASTSIM `21×21` 网格，不使用 `-ffast-math`，不把实数等价冒充逐位等价。
- **完成门**：

  2. FASTSIM 平方判定单独核对黏滑边界、摩擦上界和 IRW 独立轮控制响应；只有双车均通过才替换。

**候选 A 运行前预登记：纵向二分中点偶次多项式归一化**

权威中点角仍为 `middle = 0.5*(outside+inside)`。设括区半宽
`h = 0.5*(inside-outside)`，两端方向向量之和的范数为 `2*cos(h)`。候选以

```text
P8(h) = 0.5 * [1 + h^2 *
  (1/2 + h^2 *
    (5/24 + h^2 *
      (61/720 + h^2 * 1385/40320)))]
```

近似 `1/(2*cos(h))`，仅用于每次二分中点的正余弦。现行外向搜索保证括区角宽不超过
`0.25 rad`，故 `|h| <= 0.125 rad`。高精度算术对该闭区间的预登记界为
`|1/(2*cos(h))-P8(h)| < 6.6e-12`；在最大半宽处，由端点和生成的中点单位向量范数相对
不足约 `1.30e-11`。这是局部解析误差界，不是整车输出界；近似端点会递归参与下一次归一化，
且重叠量接近零时可能改变一次二分分支，因此本项按数值候选资格化，不冒称逐位等价。

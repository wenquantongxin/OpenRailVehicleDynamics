# Linux x86-64 计算评价

## 运行配置

AMD Ryzen 9 9950X3D，16 核、32 线程；Ubuntu 24.04 x86-64，GCC 13.3.0＋libgomp。
Release、C++23、`-O3 -DNDEBUG`，严格浮点运算。所有运行绑定 CPU 8–15，使用 8 个不同物理核。
`OMP_NUM_THREADS=8`、`OMP_THREAD_LIMIT=8`、`OMP_DYNAMIC=FALSE`、`OMP_MAX_ACTIVE_LEVELS=1`；
BLAS 类库采用单线程。

| 工况 | 时长 / s | 方法 | 容差 rtol / q / v / z |
|---|---:|---|---|
| GZ18 直线＋AAR6，60 km/h | 20 | BDF2 | `1e-6 / 1e-7 / 1e-6 / 0.1 N` |
| GZ18 R300＋AAR5，60 km/h | 16 | BDF2 | `1e-6 / 1e-7 / 1e-6 / 0.1 N` |
| IRW R300＋四通道 AAR5，60 km/h，被动 | 50 | BDF5 | `1e-8 / 1e-8 / 1e-7 / 1e-6 N` |
| IRW R300＋四通道 AAR5，60 km/h，100 Hz 受控 | 50 | BDF5 | `1e-6 / 1e-6 / 1e-5 / 1e-6 N` |

运行命令与积分配置见[运行工具](../../../tools/dynamics_qualification/README.md)。
BDF 步长与阶数自适应，单次推进内步预算为 1,000,000；稠密输出周期 0.5 ms，受控转矩保持周期 10 ms。

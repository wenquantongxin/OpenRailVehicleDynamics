# 时间积分方法单线程计算评价

本文在同一 Release 构建、单线程和固定 CPU 亲和性下，记录 CVODE BDF、Zhai 与 Newmark 在四个
资格工况上的计算量、墙钟，以及相对 Radau5 参考轨迹的差值。方法定义见
[时间积分方法](../../models_and_algorithms/numerical_methods/TIME_INTEGRATION_METHODS.md)。

## 方法与参数

| 方法 | 配置标识 | 步长 | 参数 |
|---|---|---|---|
| CVODE BDF | `cvode_bdf2`、`cvode_bdf5` | 局部误差控制 | 方法与容差取各工况资格运行器的内置配方 |
| Radau5 | `radau5` | 局部误差控制 | 参考轨迹，容差见计算工况 |
| Zhai | `zhai` | 固定 `12.5 µs` | $\varphi=\psi=1/2$ |
| Newmark 平均加速度 | `newmark` | 名义 `12.5 µs`；Newton 迭代耗尽时减半重试，下限为名义步长的 `1/1024`，连续两次成功后加倍直至名义步长 | Newton 迭代上限 `12`；平动、角度、四元数三族尺度均为 `1e-8 / 1e-7 / 1e-6 / 10`，串联力族为 `0.01 / 0.01 / 1e5 N` |

Newton 尺度依次为位置修正、速度修正、加速度残差和差分参考值；力族依次为修正、残差和参考值。
平动族对应 `m / m/s / m/s² / m/s²`，转角族对应 `rad / rad/s / rad/s² / rad/s²`；四元数族
按存储分量定义，四项均乘最近成功初始化时各四元数的参考范数。
每次推进的内部步数上限统一取 `5,000,000`，全部运行均未触及。

## 测试基线

AMD Ryzen 9 9950X3D，16 核 32 线程；Ubuntu 24.04，Linux 6.8；GCC 13.3.0，Release、C++23、
`-O3 -DNDEBUG`，不启用 fast-math。

全部运行单线程：OpenMP 线程数与接触批 worker 均为 `1`，差分 Jacobian worker 除 Zhai 为
`0`（不适用）外均为 `1`；BLAS 类库线程数为 `1`。每个进程以 `taskset` 绑定一个逻辑 CPU，其
SMT 同胞不分配评价进程。

| 阶段 | 运行 | CPU | 并发 |
|---|---|---|---|
| S | CVODE、Zhai、Radau5 各四工况，依次运行 | 8 | 无其他评价进程 |
| N | Newmark 四工况，同时运行 | 8、9、10、11 | 四个进程共用同一块 32 MB L3 |

每个配置运行一次。

## 计算工况

| 工况 | 仿真时长 | 输出／控制钟 | CVODE | Radau5 参考 |
|---|---:|---|---|---|
| GZ18 直线＋AAR6，60 km/h | 20 s | 输出 0.5 ms | BDF2，`1e-6 / 1e-7 / 1e-6 / 0.1 N` | `1e-10 / 1e-11 / 1e-10 / 1e-5 N` |
| GZ18 R300＋AAR5，60 km/h | 16 s | 输出 0.5 ms | BDF2，`1e-6 / 1e-7 / 1e-6 / 0.1 N` | `1e-10 / 1e-11 / 1e-10 / 1e-5 N` |
| IRW R300＋AAR5，被动，60 km/h | 30 s | 输出 0.5 ms | BDF5，`1e-8 / 1e-8 / 1e-7 / 1e-6 N` | `1e-12 / 1e-12 / 1e-11 / 1e-10 N` |
| IRW R300＋AAR5，100 Hz 全状态受控，60 km/h | 30 s | 输出 0.5 ms；控制 10 ms | BDF2，`1e-6 / 1e-6 / 1e-5 / 1e-6 N` | `1e-10 / 1e-10 / 1e-9 / 1e-10 N` |

容差按 `rtol / q / v / z` 排列。受控工况包含 `3000` 个 10 ms 保持区间；非终末控制边界更新保持
输入后同步积分器，共 `2999` 次同步。

R300 线路的名义分段为 `50–100 m` 进入缓和段、`100–600 m` 圆曲线，随后进入退出缓和段；分段
接缝采用既有的 `3 m` 平滑过渡。AAR5 不平顺从 `160 m` 后引入，AAR6 序列的激励区间为
`50–300 m`。按各车轮实际站位，四个窗口均经过不平顺激励；GZ18 直线还覆盖 AAR6 序列结束后的
零不平顺尾段，三个 R300 窗口均未到达曲线退出阶段。

## 度量

精度以同工况 Radau5 轨迹为参考，按整数纳秒输出时刻逐样本对齐。下文差值均为相对这条参考轨迹的
差值，不是相对精确解的误差。

- 横移与摇头：逐载体求差值均方根，GZ18 为四个轮对，IRW 为四个轴桥；表中给出均方根范围与全部
  载体的最大绝对差。
- 轮轨力：每个车轮、每个样本把各接触斑在接触坐标系中的 `N`、`Tx`、`Ty` 分别相加，无接触斑记为
  零；全部车轮与样本池化后求均方根和最大绝对差。
- 受控工况另逐控制事件、逐车轮比较转矩调理器的方向判定与限幅标志。请求转矩在 `0.5 N·m` 死区内
  时方向判定为零，否则按牵引或再生取 `±1`。

计算量取积分器统计。数值时间为后端构造、推进与同步的墙钟之和；完整进程墙钟另含模型载入、观测
重放与写出，各运行这部分为 `13–30 s`。

## 结论

- 四种方法在四个工况上全部完成。
- Zhai 步长与 Newmark 名义步长均为 `12.5 µs` 时，相对参考的横移最大差在 GZ18 两工况为 `2.6–10.4 nm`，
  IRW 被动为 `0.09–0.21 µm`，IRW 受控为 `10.8–11.3 µm`；CVODE 在资格容差下的对应值为
  `0.12–6.7 µm`、`157 µm` 与 `1.46 mm`。
- 四个工况中，Zhai 与 Newmark 相对参考的法向力差值几乎相同，二者彼此之间的法向力差值均方根只有
  各自相对参考值的 `1/17–1/8`。这一量级的法向力差值主要是两种方法共同相对参考轨迹的部分，
  不能据此判定哪条轨迹更接近精确解。
- Newmark 每步平均 `1.5–2.0` 次 Newton 迭代，每次迭代重建差分 Jacobian，差分右端求值约占其
  右端求值的 `97%`（按调用次数计）。Zhai 每个成功步求值一次右端，不进行 Newton 迭代，也不形成
  差分 Jacobian；构造与同步另有初始化求值。各后端共用的右端接触批计算支持多 worker 并行，本文
  采用单线程。

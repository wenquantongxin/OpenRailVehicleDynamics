# GZ18 时间积分方法单线程计算评价

本文在同一 Release 构建、单线程和固定 CPU 亲和性下，记录四种积分方法在 GZ18 两个工况上的
计算量与墙钟，以及 CVODE BDF2、Zhai、Newmark 相对 Radau5 参考轨迹的差值。方法定义见
[时间积分方法](../../models_and_algorithms/numerical_methods/TIME_INTEGRATION_METHODS.md)。

## 方法与参数

| 方法 | 配置标识 | 步长 | 参数 |
|---|---|---|---|
| CVODE BDF2 | `cvode_bdf2` | 局部误差控制 | 容差见计算工况 |
| Radau5 | `radau5` | 局部误差控制 | 参考轨迹，容差见计算工况 |
| Zhai | `zhai` | 固定 `12.5 µs` | $\varphi=\psi=1/2$ |
| Newmark 平均加速度 | `newmark` | 名义 `12.5 µs`；Newton 迭代耗尽时减半重试，下限为名义步长的 `1/1024`，连续两次成功后加倍直至名义步长 | Newton 迭代上限 `12`；平动、角度、四元数三族尺度均为 `1e-8 / 1e-7 / 1e-6 / 10`，串联力族为 `0.01 / 0.01 / 1e5 N` |

Newton 尺度依次为位置修正、速度修正、加速度残差和差分参考值；力族依次为修正、残差和参考值。
平动族对应 `m / m/s / m/s² / m/s²`，转角族对应 `rad / rad/s / rad/s² / rad/s²`；四元数族
按存储分量定义，四项均乘最近成功初始化时各四元数的参考范数。
每次推进的内部步数上限统一取 `5,000,000`，本文八次运行均未触及。

## 测试基线

AMD Ryzen 9 9950X3D，16 核 32 线程；Ubuntu 24.04，Linux 6.8；GCC 13.3.0，Release、C++23、
`-O3 -DNDEBUG`，不启用 fast-math。

全部运行单线程：OpenMP 线程数与接触批 worker 均为 `1`，差分 Jacobian worker 除 Zhai 为
`0`（不适用）外均为 `1`；BLAS 类库线程数为 `1`。每个进程以 `taskset` 绑定一个逻辑 CPU，其
SMT 同胞不分配评价进程。

| 方法 | CPU | 同时运行条件 |
|---|---|---|
| CVODE、Zhai、Radau5 | 8 | 逐进程执行，无其他评价进程 |
| Newmark | GZ18 直线为 8，GZ18 R300 为 9 | 与另两个绑定 CPU 10、11 的单线程评价进程同时启动；四个进程共用同一块 32 MB L3 |

每个配置运行一次。Newmark 的并发负载与其余方法不同，墙钟不用于严格同场条件下的速度倍率比较。

## 计算工况

| 工况 | 仿真时长 | 输出周期 | CVODE | Radau5 参考 |
|---|---:|---|---|---|
| GZ18 直线＋AAR6，60 km/h | 20 s | 0.5 ms | BDF2，`1e-6 / 1e-7 / 1e-6 / 0.1 N` | `1e-10 / 1e-11 / 1e-10 / 1e-5 N` |
| GZ18 R300＋AAR5，60 km/h | 16 s | 0.5 ms | BDF2，`1e-6 / 1e-7 / 1e-6 / 0.1 N` | `1e-10 / 1e-11 / 1e-10 / 1e-5 N` |

容差按 `rtol / q / v / z` 排列。两个工况分别含 `40,001` 和 `32,001` 个输出样本，均包含首末时刻。

R300 线路的名义分段为 `50–100 m` 进入缓和段、`100–600 m` 圆曲线，随后进入退出缓和段；分段
接缝采用 `3 m` 平滑过渡。AAR5 不平顺从 `160 m` 后引入，AAR6 序列的激励区间为
`50–300 m`。按各车轮实际站位，两个窗口均经过不平顺激励；直线工况还覆盖 AAR6 序列结束后的
零不平顺尾段，R300 窗口未到达曲线退出阶段。

## 度量

精度以同工况 Radau5 轨迹为参考，按整数纳秒输出时刻逐样本对齐。下文差值均为相对这条参考轨迹的
差值，不是相对精确解的误差。

- 横移与摇头：逐轮对求差值均方根；表中给出四个轮对的均方根范围与全部轮对的最大绝对差。
- 轮轨力：每个车轮、每个样本把各接触斑在接触坐标系中的 `N`、`Tx`、`Ty` 分别相加，无接触斑记为
  零；全部车轮与样本池化后求均方根和最大绝对差。

计算量取积分器统计。数值时间为后端构造、推进与同步的墙钟之和；完整进程墙钟另含模型载入、观测
重放与写出。

## 结论

- 四种方法在 GZ18 两个工况上全部完成。
- Zhai 步长与 Newmark 名义步长均为 `12.5 µs` 时，相对参考的横移最大差为 `2.6–10.4 nm`；
  CVODE BDF2 在表列容差下为 `0.12–6.7 µm`。
- Zhai 与 Newmark 在两个工况中相对参考的法向力差值接近，不能据此判定哪条轨迹更接近精确解。
- Newmark 每步平均约 `2.0` 次 Newton 迭代，每次迭代重建差分 Jacobian，差分右端求值约占其
  右端求值的 `97%`（按调用次数计）。Zhai 每个成功步求值一次右端，不进行 Newton 迭代，也不形成
  差分 Jacobian；构造另有初始化求值。各后端共用的右端接触批计算支持多 worker 并行，本文采用单线程。

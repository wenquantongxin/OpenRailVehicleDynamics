# ADR-0004：多模型本地性质门，单个高耦合在线漂移门

- 状态：**Accepted**
- 决策日期：2026-08
- 相关：ADR-0001、ADR-0002

## 背景

G37–G38 的四类模型分别承担解析、能量、虚功和 ABA/RNEA 往返等性质验收；这些测试在同一进程内运行，失败时能直接指出公式、坐标系或拓扑错误。若把四类模型及其全部工况再复制到 Drake/ORVD 双进程台架，主要增加的是建模协议、进程启动和重复计算，而不是新的独立预言机。

跨进程比较仍有独立职责：发现 ORVD 与固定 Drake 参考之间的持续漂移，并确认严格递增的必需观测集合没有缺口。它不应替代本地解析证据，也不应仅为覆盖数量复制后者。

## 决策

动力学资格采用两层证据：

1. 本地性质层运行四类类型化程序模型：单转动、单移动、转动—移动—焊接混合树与反向分支、关节树加显式自由体。模型只连接能辨识具体错误的具名工况，不做笛卡尔积。
2. 在线漂移层只运行一个同时含旋转安装座、反向分支、串联关节和显式自由体的高耦合模型，并覆盖动态与近零工作点。要求链严格从位置扩展至外力与前向动力学，缺失任一必需观测即失败。

只有当一种拓扑或工况存在本地性质门无法覆盖、且确需跨实现参照才能识别的独特漂移模态时，才把它加入在线层。测试数量、模型数量或历史覆盖率本身不是加入理由。

## 后果

- 日常在线门保持快速，且不会把同一证据维护两份。
- 单移动与焊接复合惯量仍由本地解析/ABA-RNEA 往返承担，不声称已被跨进程比较覆盖。
- 在线模型不是完整产品模型集合；其结论仅是已声明观测面上的持续漂移检查。
- 若以后扩充在线模型，必须说明新增的独立判别力，不能以“更全面”为唯一理由。

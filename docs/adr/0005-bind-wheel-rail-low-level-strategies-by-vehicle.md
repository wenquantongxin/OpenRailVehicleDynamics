# ADR-0005：按车型绑定两处轮轨低层策略

- 状态：**Accepted**
- 决策日期：2026-08
- 相关：ADR-0004、迁移路书 G52

## 背景

近期 WRL 资格化路径中，GZ18 与 IRW 在两处低层处理上使用不同合同：车轮型面进入接触几何前的节点
准备方式，以及轨型截面相对共享轨道系的侧滚 y-z 输运。它们不是同一语义的“旧版/新版”，也不是
用户可以自由混搭的算法菜单；每一种都已经进入相应车型的已复现实验。过早删掉其中一支会改变尚未完成
统一资格化的车型，保留运行期开关又会把临时迁移差异变成长期公共接口。

## 决策

两条策略轴均使用具名类型，并在车型接触人格构造时一次绑定，之后不可切换：

1. 车轮型面预处理在“等弧长重扫后建立第二自然三次样条”与“从源点首端起按横坐标重离散并作分段
   线性轮廓”之间选择。两个步长同时启用必须在构造期拒绝。GZ18 绑定前者；IRW 绑定后者。
2. 型面/轨道侧滚 y-z 输运在“抑制”与“施加”之间选择。GZ18 绑定抑制；IRW 绑定施加。数学只产生
   侧滚、横向与竖向三个偏移；真实线路位姿的取得和把策略接入车辆系统属于 G53 及后续工作。

策略不从环境变量读取，不以布尔量留在接触热路径，不进入通用车型 JSON，不提供任意组合注册表，
也不以“兼容”“旧”“新”命名。G52c 的 GZ18 bundle 显式保存其绑定，核心数学仍保持车型中立。

## 后果

- GZ18 能复现其已资格化的等弧长重扫与关闭输运语义；IRW 尚未装配不等于其另一绑定已失效。
- 两条轴的输入输出和所有权明确，但公共面不会长成可随运行切换的策略袋。
- 待两车均落地并由专项对拍证明某一维可以统一时，删除失去最后一个车型消费者的分支；若一维只剩
  一种实现，同一次改动还要删除该维的选择类型。
- 实施中若发现第三处同类车型分歧，必须回到架构裁决层，不得把它顺手并入本 ADR。

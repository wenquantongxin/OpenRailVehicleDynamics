# ADR-0005：轮轨低层策略由分车型绑定收口为通用实现

- 状态：**Accepted**
- 首次决策：2026-08
- 收口更新：2026-08-13
- 相关：ADR-0004、迁移路书 G52、性能路书 PERF-13、迁移决策 DEC-042、讨论记录 R035

## 背景

近期 WRL 资格化路径中，GZ18 与 IRW 曾在两处低层处理上使用不同合同：车轮型面进入接触几何前
的节点准备方式，以及型面／轨道相对共享轨道系的侧滚 y-z 输运。为避免在两车迁移完成前改变已
复现实验，本 ADR 最初把它们作为迁移期的具名车型绑定保存，同时禁止运行期切换、任意混搭、环境
变量覆盖和通用车型 JSON 配置，并明确约定：两车均落地且专项对拍支持统一后，删除失去消费者的
分支及选择层。

历史绑定为：GZ18 使用 `0.5 mm` 等弧长重扫、第二自然三次样条和抑制态侧滚输运；IRW 使用
`0.1 mm` 源横坐标重离散、分段线性可见轮廓和施加态侧滚输运。这两组绑定是冻结 WRL 的迁移
证据，不是必须永久保留的车型物理身份。

两车迁移和长窗资格完成后，完整 `30 s` IRW B／C 候选把 IRW 对齐到 GZ18 的数值方法。在严格
`0.5 ms` 输出时钟、IRW B 的 N5 积分配方和 IRW C/P179 的 J0 配方下，候选相对既有主线基线的
动力学推进墙钟分别增加约 `3.34%` 和 `3.92%`。这是单次候选与既有基线的比较，不是稳定性能
金标。另一方面，IRW C 相对同人格 SIMPACK Realtime 的原生同时间四轴横移／摇头八个宏观
通道 RMS 均改善约 `35%–69%`；同里程口径有 6/8 改善，另两项仅回退 `2.23% / 0.05%`。控制
事件种类、序号、时刻和导向开关保持不变。项目负责人接受这项小幅计算代价，以换取唯一实现、
更小维护面和受控 IRW 的总体精度改善。

本次收口不重开高接触角公式，也不改变车型物理身份。标称半径、轮型资产、轨道半径与不平顺、
车辆拓扑、穿透等效系数以及刚性轮对／独立旋转车轮仍由各车型分别定义。

## 决策

1. GZ18 与 IRW 的产品车轮型面都在物理右侧点列上按 `0.5 mm` 等弧长重扫，再对重扫节点建立
   第二条自然三次样条；钢轨继续使用现行共享自然三次样条。
2. 左轮节点由右轮重扫结果作精确镜像得到，不在已镜像点列上独立重扫。左右侧因此共享同一网格
   相位，余量短段不能移到型面的另一端。
3. 型面／轨道相对共享轨道系的侧滚 y-z 输运统一抑制。真实车辆和线路位姿仍由既有运动学合同
   提供；本项只删除随车型切换的额外型面输运。
4. 删除源横坐标重离散、施加态侧滚输运及其选择层。产品不保留运行期开关、兼容枚举、环境变量
   或无消费者的备用实现。
5. 高接触角方法保持现状。若未来要改变高角公式或重新引入另一种型面处理，必须作为新的科学候选
   单独资格化并形成独立裁决，不能借用本次通用化静默进入。

## 后果

- 两车共享同一低层数值方法，但车辆身份仍由车型配置和拓扑表达；“通用实现”不等于把 IRW
  改造成 GZ18。
- 本 ADR 的早期分车型绑定保留为历史迁移背景，不再描述当前 ORVD 产品路径。源横坐标重离散、
  施加态输运及其策略选择层不再有产品消费者。
- IRW B／C 的约 `3.34% / 3.92%` 推进代价是负责人已接受的产品取舍，不得写成性能提升，也不得
  由这一次运行推导为长期稳定回退；PERF-13 仍负责现行实现的双车长窗与跨平台闭包。
- IRW C 的宏观响应改善支持本次系统级裁决；IRW B 尚无当前严格时钟下同人格 SIMPACK 直接对拍，
  因此不宣称 B 获得同类精度提升。
- SIMPACK `.prw/.prr` 的 `inversion` 仍只属于开发期互操作元数据，不进入产品接触求解路径。

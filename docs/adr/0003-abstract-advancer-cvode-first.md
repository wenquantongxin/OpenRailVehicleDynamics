# ADR-0003：抽象推进器接口，首个后端是 CVODE

- 状态：**Accepted**
- 决策日期：2026-07
- 相关：ADR-0002

## 背景

时间推进有两件事必须分开：**推进循环的语义**（事件何时发生、状态何时提交、被拒绝的步
如何回退）与**积分器的数值方法**。把两者揉在一起，换积分器就会连带改变事件语义。

## 决策

整车推进循环定义**抽象推进器接口**，**首个也是当前唯一的后端是 CVODE**。

接口须承载的语义：

1. 初始化次序，以及失败与提前终止的传播。
2. 同刻事件的稳定排序，以及状态在事件前后的可见性。
3. 区分"下一次发布时刻"与"下一次更新时刻"，并据此夹持积分边界。
4. **事务语义**：右端求值不产生副作用；被接受的步恰好提交一次；**被拒绝的步不得污染
   已接受的状态**——包括不在状态向量里的量，例如温启动提示与积分型累加器。
5. 状态、参数或输入改变后，显式通知后端是否需要重新初始化。

**未准入的能力在首版接口中不存在**：不预留目录，不设占位实现，不留兼容别名。一个"暂时
不支持"的入口与一个已实现的入口在调用点上无法区分，只会把失败推迟到更贵的地方。

## 后果

- 事件语义与数值方法解耦，日后增加第二个后端不必重新裁决事件行为。
- 只有一个后端时抽象层有退化成空壳的风险，因此接口以上述语义清单为准，而不是以"将来
  可能需要"为由扩张。
- 事务语义的验证在 G45：被拒绝的步之后，Context 必须与该步之前完全一致。

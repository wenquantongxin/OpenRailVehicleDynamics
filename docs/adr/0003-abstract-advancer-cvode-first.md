# ADR-0003：抽象推进器接口，首个后端是 CVODE

- 状态：**Accepted**
- 决策日期：2026-07
- 相关：ADR-0002

## 背景

时间推进有两件事必须分开：**推进循环的语义**（事件何时发生、状态何时提交、被拒绝的步
如何回退）与**积分器的数值方法**。把两者揉在一起，换积分器就会连带改变事件语义。

## 决策

整车推进采用两层接口。`ContinuousStateAdvancer` 是只负责端点、密集输出和重初始化的数值
后端接口，首个且当前唯一准入的后端是 CVODE；其上的系统推进/事件执行器负责接受态提交、
边界夹持和事件时序。数值后端不承担尚不存在的事件目录或向量外状态。

两层合起来须承载的语义：

1. 初始化次序，以及失败与提前终止的传播。
2. 同刻事件的稳定排序，以及状态在事件前后的可见性。
3. 区分"下一次发布时刻"与"下一次更新时刻"，并据此夹持积分边界。
4. **事务语义**：右端求值不产生副作用；被接受的步恰好提交一次；**被拒绝的步不得污染
   已接受的状态**——包括不在状态向量里的量，例如温启动提示与积分型累加器。
5. 状态、参数或输入改变后，由系统推进层把完整接受端点显式交给数值后端重初始化。

事件计划锚定全局相位 `offset + n·period`，不是从初始化时刻重新起算。初始化只派发一次
初始化更新；初始化或恢复后首次周期事件必须严格晚于当前时刻，不能在同一网格点重复派发。
同一时刻先让全部更新从同一个 `x⁻` 计算试算值，全部成功后一次提交为 `x⁺`，再按声明顺序
发布；发布观察 `x⁺`。这是既有 CVODE 路径的语义，蓄意不同于 Drake 发布观察 `x⁻`。

G42 收口时，首个系统图只有一个多体组件且没有事件生产者，因此初始化、周期更新和周期发布
计划都为空，未建立无消费者的事件接口。上述语义在第一位真实事件消费者接入时成为编译计划
与执行器的验收门，而不是由一个空回调框架冒充已实现。

当前 `ContinuousStateAdvancer` 只实现上述分层中的数值后端边界。第 1–4 项涉及系统接受态、
事件排序和发布可见性的部分属于其上的执行器，不得反向塞进数值后端接口；没有事件生产者时，
只验收连续状态的试算、成功提交和失败原子性。

G54 把后端推进收窄为唯一的 `AdvanceOneInternalStepToward()`：CVODE 以 `CV_ONE_STEP` 返回一个
内部接受端点及其最近密集输出区间，系统层显式循环到公开目标。后端端点必须重新装入专用试算
上下文，不能把最后一次 RHS 试算冒充接受端点。系统推进器拥有该试算上下文，RHS 桥只借用它；
因此系统层能在每个内部端点更新数值历史，而 RHS 仍拿不到公开接受上下文。

当前第一位数值历史消费者是轮轨局部分支站位。近期冻结 GZ18／IRW 工件均固定每个接受端点更新
一次且关闭站位速度预测，RHS 只消费最近 accepted `s`；因此 ORVD 每个唯一载体只存一个站位，
不为未消费的 `sdot/dt` 建状态或版本。公开上下文持 accepted 站位，试算上下文持 candidate 站位；
端点只重算四载体投影，不重复执行八轮接触核。公开推进成功时，时间、`[q;v;z]` 与站位一次提交；
任一后端或投影失败都保持公开接受态不变，并要求从该接受态显式重初始化。

G54 不预建内部步观察器。G55 的真实密集采样消费者出现时，允许在本层增加一条只服务单次公开
推进的窄事务采样通路；不得借此建立通用事件、回调或发布注册表。

**未准入的能力在首版接口中不存在**：不预留目录，不设占位实现，不留兼容别名。一个"暂时
不支持"的入口与一个已实现的入口在调用点上无法区分，只会把失败推迟到更贵的地方。

## 后果

- 事件语义与数值方法解耦，日后增加第二个后端不必重新裁决事件行为。
- 只有一个后端时抽象层有退化成空壳的风险，因此接口以上述语义清单为准，而不是以"将来
  可能需要"为由扩张。
- G45 先验证当前真实系统图的连续状态事务：被拒绝的推进之后，已接受 Context 必须与推进
  之前完全一致，成功边界只提交一次。事件专有的向量外状态与同刻 update/publish 顺序，在
  G46 后第一位真实事件生产者出现时按本 ADR 实现；不得用测试占位框架冒充已完成。
- G54 以后不存在可绕过内部接受端点历史更新的后端批量推进入口；批量语义只属于系统层。

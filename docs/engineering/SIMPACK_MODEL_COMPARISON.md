# SIMPACK 模型对照

本文保留 GZ18 已完成专项中的比较口径、结果与模型边界，并说明仍需核实的 SIMPACK 差异。各项结果只对应所列输入、观察量与比较域；当前整车工况及响应图见[整车验证](../../README.zh-CN.md#整车验证)。

## 已核实结果

### GZ18 直线 AAR6：激活与完整包络

两次专项均从 60 km/h 已解析移动状态独立开始，线路水平、零超高，车辆布局参考站位为 `0 m`，四轮对初始站位依次为 `+9.1/+6.6/-6.6/-9.1 m`。双方使用相同的已解析横向、垂向 AAR6 空间点列。ORVD 使用 Release 构建、CVODE BDF、每次右端重算接触和八线程接触批求值；`0.5 ms` 密集输出不增加积分停靠点。10 s 与 20 s 分别使用独立的 SIMPACK 参考运行。

| 专项 | 比较域与观察量 | ORVD–SIMPACK 结果 |
|---|---|---|
| 10 s 激活，20001 点 | 同一整数时间序号，且双方对应轴站位同时在 `100–150 m`；四轮对质心轨道横移、摇头的原始量及相对各自初值的增量 | 各轴均方根、最大差均低于 `0.1 mm / 0.1 mrad` |
| 20 s 完整包络，40001 点 | 每轴独立的 `0.01 m` 公共站位格；分别统计激励前、`50–100 m` 淡入、`100–250 m` 全幅、`250–300 m` 淡出、`300 m` 后恢复及 `50–300 m` 总窗 | 上述原始量与初值增量的均方根、最大差均低于 `0.1 mm / 0.1 mrad`；横移最大差为后构架前轴淡出段 `93.46 µm`，摇头最大差为后构架后轴淡出段 `36.51 µrad` |

20 s 的四轴公共里程末端分别为 `342.38/339.88/326.68/324.18 m`，均覆盖至少 `24 m` 的公共恢复段。同时间曲线也显示一致的传播趋势。双方全程八轮单斑，ORVD 无连续零接触段。宏观响应满足所列目标；轮轨力差异集中于局部区段，其中淡入段前轴右轮的垂向轮载／法向力最大差约为 `67.1 kN`。

### GZ18 R300+AAR5：同义站位与曲线响应

专项从相同 `0 m` 布局参考站位、60 km/h 移动状态开始。线路为 `50+50+500+50+500 m` 的直线、入缓和、R300 圆曲线、出缓和、直线，总区间 `[0,1150] m`；纵坡为零，超高绕中心线施加，平台值 `0.12 m`、参考基长 `1.5 m`，四处接缝采用 `3 m` 五次 C² 过渡。横、垂 AAR5 点列各有 37620 点，支持域 `[60,1000] m`，已包含 `60–100 m` 淡入及 `960–1000 m` 淡出，加载时不再乘包络。

ORVD 采用 Release 构建、八线程接触批求值和 CVODE，独立连续运行 `0–16 s`；与 SIMPACK 双精度原生结果均按 `0.5 ms` 得到 32001 点。动力学比较域覆盖起始直线、入缓和及已到达的圆曲线部分。

| 比较项 | 同义观察量与比较域 | 结果 |
|---|---|---|
| 站位随时间 `s(t)` | SIMPACK 左右轨型参考标记在理想线路上的站位平均，对 ORVD 两侧接触接口实际消费的轨型参考站位平均；全窗共同原生时刻 | 四轴均方根 `1.666–1.752 mm`，最大差 `5.178–6.656 mm`；起始直线均方根仅 `0.0019–0.0025 mm`，圆曲线全幅段增至约 `2.14–2.15 mm` |
| 到达时间 `t(s)` | 在共同厘米格上，取各原生序列首个满足 `s[k] ≥ S` 的样本时刻，不作时间插值 | 四轴均方根 `0.181–0.191 ms`，最大差 `0.5 ms`；结果包含 `0.5 ms` 输出量化 |
| 轮对横移 | 四轮对刚体原点的横移，按下节不平顺观察变换；每轴 `100–250 m`、`0.01 m` 同站位格 | 各轴均方根范围 `6.49–18.62 µm`，最大差范围 `17.85–113.34 µm` |
| 轮对摇头 | 同一原点、同一里程格，采用一致的摇头表达 | 各轴均方根范围 `5.37–15.69 µrad`，最大差范围 `20.86–103.12 µrad` |
| 八轮 `Q/N/Tx/Ty` | 全窗共同原生时刻；分别统计垂向轮载、法向力和两向局部切向力 | 原生时序全接口均方根 `0.409/0.414/0.113/0.087 kN`，最大差 `12.119/12.199/2.821/2.779 kN` |

横移、摇头的均方根均低于 `0.1 mm / 0.1 mrad` 目标；只有后构架前轴约 `223 m` 处出现短窄超线，横移、摇头最长连续超线跨度分别为 `0.09 m`、`0.03 m`。双方八轮全程单斑，无持续失联或长期零力。站位仍有毫米级残差，轮轨力仍有千牛级峰值差；这些边界与宏观均方根达标同时成立。

### 线路几何的内部收敛

上述 `[0,1150] m` R300 线路以 `0.5 m` 和 `0.1 m` 两种构造节点间距独立建立：在全线 `0.5 m` 公共节点上的最大位置差为 `1.27×10⁻¹³ m`，以 `0.01 m` 密格复核不超过 `2.35×10⁻¹³ m`。这是 ORVD 中心线构造在该输入下的节点细化收敛结果。SIMPACK 的最终接缝公式与离散另见下节。

## 比较口径

- **先统一观察点与表达系。** 轮对刚体原点的线路投影，与左右轨型参考标记的站位平均不是同一个量。站位传播必须沿同义链比较；不能以两个不同观察点的差值判断动力学传播误差。直线专项把参考宏观量经 `diag(1,−1,−1)` 固定换基转换到 ORVD 标准轨道 T 系，横移、摇头各换号一次；已规范化的接触标量不随之再次换号。
- **区分基础线路与受不平顺影响的观察。** 16 s 曲线专项在左右接口各自实际消费的站位采样横向不平顺 `y_L,y_R` 及斜率 `y'_L,y'_R`，以 `ȳ=(y_L+y_R)/2`、`ȳ'=(y'_L+y'_R)/2` 形成观察量 `y_obs=y_base−ȳ`、`ψ_obs=−ψ_base+atan(ȳ')`。不改用轮对原点或单侧站位采样，也不回写动力学状态。该换算针对这组参考输出定义，不应作为所有 SIMPACK 输出的通用换号规则。
- **时间域与里程域分别保留。** 同时间使用共同原生样本；同站位先检查各轴站位有限、严格递增，只在双方覆盖交集中作相邻样本线性插值，禁止外推。到达时间使用上表的首个越站样本规则。原始量和各自初值增量分栏，不移时、滤波、去均值、缩放或拟合曲线。
- **力的对象、方向与求和层级必须相同。** `Q` 是垂向轮载，`N` 是接触法向力；局部 `Tx/Ty` 不能与轨型系分量混比。多斑时，轮侧总力须先把各斑力换到共同表达系再相加；最大法向力主斑列、各斑局部量、总力分开记录。参考文件的输出槽数不代表求解器接触斑上限，不能据此截断 ORVD 动力学。
- **将误差与覆盖范围一起报告。** 均方根配合最大差、峰值位置、持续区间和原始响应图；短峰、持续相位偏差与持续失联分别判断。每次对照记录实际输入、启动状态、积分方法与容差、接触更新方式、输出时钟及线程配置。更换求解器、输入场或模型后，先前结论不会自动覆盖新组合。

## 模型差异与待核实事项

下表区分已知表达差异与两端同义性待核的项目，列出各自的证据范围与核实条件。

| 事项与状态 | 当前表达及可能影响 | 关闭问题所需核验 |
|---|---|---|
| [线路接缝与离散](../models_and_algorithms/track_geometry/TRACK_GEOMETRY_AND_FRAMES.md)：待核实 | ORVD 的曲率、超高接缝匹配值及一、二阶导数，中心线采用解析航向和八点高斯求积。SIMPACK 最终 `3 m` 叠加平滑多项式及 Track Line 离散／插值尚无完整同义证明；会影响位置、姿态及传播相位。中心线滚转和活动 `1.5 m` 超高参考基长已明确，不与此问题混合。 | 无车辆、同一段表，在四个段界及各自 `±1.5 m` 内比较高精度中心线、姿态、曲率、超高及导数；分别识别公式差异与离散误差。 |
| [Kalker 表外拼接](../../libs/wheel_rail_contact/src/kalker_coefficient_table.cc)：待核实 | 当前有限表在 `a/b=0.1`、`10` 之外切到细长椭圆渐近式，无混合区。两端可能存在系数跳跃并传入切向刚度；渐近式的一手理论出处及 SIMPACK 精确切换仍需核实。 | 补全公式出处，以同一泊松比与接触输入跨越两个边界比较系数及切向力；不能由未进入表外的车辆工况推断表外一致。 |
| [不平顺采样速率与材料速度](../../libs/wheel_rail_contact/src/wheel_rail_contact_model.cc)：待核实 | ORVD 以静止钢轨材料点速度为零。`y'(s)·ṡ`、`z'(s)·ṡ` 描述车辆扫过固定空间场的采样变化，不作为非零轨速减入接触相对速度。SIMPACK 对应内部消费方式尚未核实；不同解释会影响蠕滑及法向接近速度。 | 同一空间场、接触状态与材料点，核对参考模型的相对速度定义及原生输出；采样导数本身不能证明材料在运动。 |
| [完整轨型姿态与接触力基](../../libs/wheel_rail_contact/src/contact_creepage.cc)：待核实 | ORVD 用完整轨型姿态放置钢轨材料参考点；法向速度、蠕滑与扳手共用的接触基仍由横断面坡角及滚转激励构造，不整体叠加方向、高低不平顺的斜率姿态。此层在 SIMPACK 中是否同义尚未核实，会影响力方向与虚功。 | 对同一接触输入分别核对点位、接触基、`N/Tx/Ty`、空间扳手及虚功，不能只比较标量法向载荷。 |
| [非零纵坡上的速率](../../libs/forces/src/wheel_rail_contact_force_plan.cc)：待核实 | ORVD 以水平投影站位 `s` 参数化线路，三维路径速率为 `ℓ̇=√(1+g²)·ṡ`；位姿归约消费 `ṡ`，蠕滑参考速度消费 `ℓ̇`。上列水平专项无法区分二者，SIMPACK 对应归一化速度仍需核实。 | 在明确非零纵坡的同一状态比较站位速率、路径速率及蠕滑率；先统一上坡为正的纵坡定义与坐标变换。 |
| [IRW 主动转矩轴与符号](../../libs/forces/src/independent_wheel_active_torque_plan.cc)：表达差异 | ORVD 以轴桥 `+Y` 的世界方向施加轮侧正转矩、构架反转矩。参考 Type-110／Type-93 使用构架 From 标记的 Y 分量，From 侧原始正号与轮侧正号相反；构架轴与轴桥轴在相对转动后可不共轴。相同标量不一定产生相同空间力偶。 | 按实际输出作用侧换号后，在两轴可区分的同一姿态比较空间力矩与虚功，再核对所用控制模型的实际输入映射。 |
| [IRW 控制观察时相](../../libs/configuration/src/irw_full_state_control_event_session.cc)：通信路径待核实 | 当前 ORVD 在 100 Hz 事件读取当前接受机械状态；启动先作一次只推进控制记忆的更新，再以同一机械状态生成首个 `10 ms` 保持量。既有 SIMAT 对照曾采用上一通信拍机械输入；不能将其泛化为所有 SIMPACK 路径，或把启动双更新与观察龄混成同一延迟。 | 对实际参考路径逐事件记录输入状态时刻、初始化更新、事件序号及保持区间，分别比较请求、调理后及实际保持转矩；采样行号不代替事件序号。 |

IRW 构架侧衬套的参考架本构、真实端点与支承矩见[参考架线性衬套](../models_and_algorithms/force_elements/REFERENCE_FRAME_LINEAR_BUSHING.md)；接触与线路公式见[模型与算法](../models_and_algorithms/README.md)。

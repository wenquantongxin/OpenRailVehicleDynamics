测试由 CTest 注册。`BUILD_TESTING=OFF` 时整个测试树不进入构建。

## 判定方式

测试以**退出码**判定，失败时在现场打印足以定位的诊断。

测试**不读取**金标、`expected` 文件、快照或哈希。没有任何"上次的输出"参与判定：
一个只能与自己的历史输出比较的测试，无法区分"仍然正确"和"一直错着"。

## 观测语义

判定方按物理量纲区分角度、单位四元数分量、平移、力和力矩，并为近零量使用各自单位的
绝对限。混合自由度按分量保留 N 与 N·m 的区分，不把两者折叠成一种量。

跨实现比较物理观测时，旋转不逐元素比较：九个元素差不合成有意义的姿态误差。矩阵元素
只作传输，由判定方把完整旋转作为 SO(3) 元素检查和比较。位姿组合的代数单测是另一类
契约：它直接逐元素验证矩阵乘法定义，并使用表示精度量级的界限。

## 跨进程比较

参考发射器只产出观测名称与原始数值；物理量类别、必需观测集合与容差判决由判定方独占。
若两侧各自声明验收规则，共享同一个错误规则的两侧就能互相背书。

Drake 是迁移期的比较参照，不是本项目交付物的依赖，因此
`ORVD_BUILD_DRAKE_REFERENCE_TESTS` 默认关闭。开启需用 `drake-reference` 预设，Drake
位置由标准 `CMAKE_PREFIX_PATH` 提供，仓库不写入任何机器路径：

```bash
cmake --preset drake-reference -DCMAKE_PREFIX_PATH=<drake 安装前缀>
cmake --build --preset drake-reference
ctest --preset drake-reference --output-on-failure
```

台架先用同一 Drake 参考实现的两个独立进程证明管道、解析与裁判可用，并确认注入的扰动会
被发现；这一步本身不构成候选结论。G31–G36 已接入独立的 ORVD 候选端，随后用能力具名且严格
扩展的必需观测集合分别覆盖位置、空间运动学、微分运动学、质量矩阵、逆动力学/力元与外力/前向动力学并与 Drake 比较；启动器拒绝
把同一个可执行文件同时充当参考端和候选端。

空间速度的长期解析测试不从另一条被测查询制造期望值，而是直接使用刚体关系、点移公式和坐标
变换计算。跨进程比较另行覆盖所有场景刚体的角速度与刚体原点平移速度、具名的三坐标系相对
速度以及速度状态回读。内部缓存测试用提交重算次数区分「被标为过期」与「查询时真的重算」。

微分运动学的本地解析测试逐列用公共位姿中心差分核对刚体固定点 Jacobian，并以
`A(vdot)-A(0)=J·vdot` 核对显式加速度。跨进程端使用独立于上下文速度、分量两两不同的稠密
速度探针比较正映射与每个刚体质心处的 `J·probe`，并用不是由正映射生成的独立 qdot 比较逆
映射；一次稠密响应不声称等价于完整 Jacobian，完整列序与符号由本地逐列有限差分承担。

质量矩阵的公共解析测试不调用第二条质量矩阵实现制造期望值，而是从每个刚体的公共位姿、刚体
原点空间速度、偏心质心和中心惯量组装动能，再用基向量与两两和的极化恒等式恢复完整算子。内部
测试另将复合刚体算法逐列与预分配逆动力学交叉，并让公共刚体顺序不同于森林 Mobod 顺序。跨进程
要求集逐列覆盖全部广义力响应，按每个输出行分别保留 N 与 N·m 的量纲。

持续在线漂移门只运行一个高耦合场景：旋转且平移的安装座、反向转动分支、串联关节和显式自由体共同出现，并分别施加动态与近零激励。单转动、单移动和混合焊接模型的解析/性质资格保留在快速的本地测试中，不在跨进程套件重复构造一份慢速矩阵；证据分工见 [ADR-0004](../docs/adr/0004-focused-dynamics-qualification.md)。在线要求链在质量矩阵之后严格追加速度偏置、重力、阻尼、所需广义力、前向广义加速度和完整状态导数；任一必需观测缺失即失败。

## 参考缓存语义

缓存失效语义探针在钉死的 Drake 上实测运动学缓存行为：重复求值不重算；改 `q` 或改 `v`
都使位置与速度缓存共同过期——Drake 当前只能整段取用可变 `q/v`，共同失效是参考实现的
保守现状，不是 ORVD 的要求；过期条目按需分别重算，序号只在真的重算时增长；Context
之间彼此隔离。序号只判「不变」或「严格递增」，不锁定绝对值或恰好加一。

## 位姿组合契约

四个位姿组合函数由 ORVD 自研以满足 vendored 声明，因此它们的正确性没有上游实现兜底。
`math/verify_double_pose_composition_contract` 链接**真实符号**
`drake::math::internal::Compose*`，逐一检查四条定义式，并覆盖声明允许的四种输出重叠形态：
输出独立、输出别名第一个输入、输出别名第二个输入、三个实参同为一个对象。

期望值一律先用裸 Eigen 按定义算出，且在调用之前算出——输出别名输入的调用会覆盖掉本该
读取期望值的那份数据。期望值刻意不经 `RotationMatrix::operator*`、
`RigidTransform::operator*` 或 `InvertAndCompose`：那些会绕回被测符号，实现与期望便会
按构造相符，测试也就什么都证明不了。

该测试的容差不是本项目的 `1e-8` 跨实现口径。那个口径用于比较条件良好的 `double` 物理量；这里是同一代数
恒等式在同一算术下的两种算法，诚实的界是表示精度自身的小倍数，按参与量级缩放。

## 连续状态推进桥

G43 的聚焦测试使用两个不同运行期维数的模型核对 `[q; v]` 双向映射，不使用固定车型维数；逐项互异的绝对容差原样保留。RHS 只持有专用试算上下文，与已接受上下文在结构上隔离；合法试算与现有静态计划一致，非法状态不改接受态或调用方导数输出；异系计划在取得试算状态前即拒绝。当前桥显式选择无调用期外力，现有连续系统的接受/试算提交归 G45，真实事件事务留给 G46 后出现的首个事件生产者。

G44 的聚焦测试直接运行真实 CVODE 后端：自由落体与线性振子对照解析解，一维非自治方程守住回调时间，最近成功内步守住密集输出区间；RHS 抛出后验证原异常类型、公开端点不变、旧密集输出失效、继续推进被封锁，并经显式重初始化恢复。测试不引入 SUNDIALS 故障注入钩子，也不复制求解器内部算法。

G45 的聚焦测试以单自由度阻尼解析解参数化验证真实系统桥、CVODE BDF2、Radau5 与同一套接受提交；外部重写 q/v 和关节阻尼后，显式同步使所选后端与试算上下文共同进入下一段且不影响接受上下文。质量与惯量为零的转动支路稳定触发真实 ABA RHS 失败，接受时间和状态不发布、再次推进被封锁、重初始化后可重新进入 RHS。非法完整状态直接验证“时间 + `[q;v]`”拒绝原子性；不为不可自然产生的成功端点加入伪后端或故障钩子。

G50 把同一桥扩展为 `[q;v;z]`，并以真实车辆力元计划验证具名标称力与串联力状态。力元名称只在
设置阶段解析为系统绑定的强类型索引；右端热路径仍用冻结序号。解析纵切同时核对标称力产生的
分段常加速度与串联元的指数衰减，确认关节阻尼和标称力都由统一入口同步到所选后端的试算上下文；
同一系统事务合同分别覆盖默认 CVODE BDF2 与研究用 Radau5，不复制车辆级积分循环。

## 积分器资格接缝

Radau5 核心测试除刚性、稠密输出和异常分类外，还直接复用生产 Newton 判定，锁定默认 `NIT=7`
时第 6 次预测的 `dyth<1` 接受与 `dyth==1` 拒绝边界；四维串行 Jacobian 基线另锁定一列一任务、
中间列 recoverable 只缩放并重试该列、fatal 不继续求后续列、RHS 计数分区和端点原子性。资格测试穷尽
`TimeIntegratorQualificationCase` 的 8 个 backend/tier 组合及四档容差缩放；轻量 Python CTest
另锁定三个 runner 的旧／新参数数量、输出目录位置，以及非法尾 case 的退出码，不以整车长窗承担
命令行解析合同。轻量 CTest `verify_serial_qualification_comparison_contract` 严格校验
INT-07A 冻结的 v2 串行 manifest `int07a_serial_baseline_v2`，并确定性展开 GZ18/IRW
两个场景的 16 组 argv；它拒绝未知字段、非整数时钟、非串行身份、非严格浮点身份和性能排名，不执行
长窗。独立工具链测试证明干净 Release 配置可通过，并让 `-ffast-math`、`-Ofast`、有限数学假设及
已知等价选项失败；目录级 `-ffp-model=fast`、响应文件中的危险选项和不透明响应文件也会在最终编译
命令处被拒绝，可读的安全相对响应文件则通过。测试还锁定不执行编译启动器的生成器和既存启动器链
必须在配置期响亮失败。该 v1 合同是浮点安全类别而非跨构建逐位身份：编译器默认 contraction、
`-ffp-contract=fast/off` 与融合乘加均允许；两个显式 contraction 选项都必须通过配置审计和最终编译
启动器的真实构建正例。跨编译器／目标构建按协议数值预算比较；同一二进制在不同固定槽 worker 数
下仍必须逐位一致。

独立正确性回归另覆盖每次正长度调用的一次性 stop 吸附及拒步后不重复吸附、持续阶段／误差修正
recoverable 的原异常因果、recoverable 后独立真奇异的优先级、非有限 shift／矩阵／分解分类、正负
大状态的有符号可表示 Jacobian 扰动，以及缩放平方和范数；Newton 修正与误差 WRMS 由两个定向
大尺度场景分别证明不会因先平方而假溢出。适配器测试验证自定义 recoverable 类型、
输出 sentinel、端点、稠密区间、统计、失败封锁和成功重初始化；系统事务测试另要求 accepted
投影历史更新后 Radau5 重建线性化。局部线路投影测试覆盖尺度化残差、严格正二阶条件、至多两次
Newton 校正、定义边界延长和非法输入。
实／复近奇异资格通过源码树专用接缝直接复用生产矩阵形成、分解和求解，以三个逐级缩小谱隙检查
相对后向残差、解析前向误差界和仓外官方 DECSOL oracle；测试不向产品加入条件数阈值。

真实 GZ18 与 IRW 被动/100 Hz 控制短窗把现有全串行运行作为 correctness oracle，再要求
4/8/12/16/32-worker 的完整
`continuous_states.tsv`、物理观测、接触斑、终态及数值统计保持一致。完整状态表按整数纳秒时钟无损
保存 `[q;v;z]`；跨后端自由体与 Ball-RPY 姿态必须使用 INT-07 协议的 rotation-log 误差，不直接相减
raw quaternion／Euler 坐标。

## 安装消费者

G46 的安装测试先把当前构建安装到临时前缀，再整体迁移该前缀；随后从独立源码目录仅通过
`find_package(OpenRailVehicleDynamics CONFIG REQUIRED)` 构建程序。程序用公共门面建立阻尼
转子，经系统组装和真实 CVODE 后端推进，并与解析解比较。安装元数据不得含原安装前缀、源码
路径或 `/opt`。同一测试用 CMake 的平台运行期依赖解析检查已运行消费者的动态闭包；未解析边
明确失败，并由一个实际装载的 Drake 标识共享库证明判别会响。测试不使用 `ldd`、`readelf`
或 GNU 链接器参数。测试夹具显式复用当前构建实际采用的 Eigen、fmt 与 SUNDIALS 配置目录，
因此同样适用于依赖位于自定义离线目录的开发环境；安装元数据另行钉住 fmt 查找不得受 `PATH`
上其他工具链污染。

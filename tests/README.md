测试由 CTest 注册。`BUILD_TESTING=OFF` 时整个测试树不进入构建。

## 判定方式

测试以**退出码**判定，失败时在现场打印足以定位的诊断。

测试**不读取**金标、`expected` 文件、快照或哈希。没有任何"上次的输出"参与判定：
一个只能与自己的历史输出比较的测试，无法区分"仍然正确"和"一直错着"。

## 观测语义

判定方按物理量纲区分角度、单位四元数分量、平移、力和力矩，并为近零量使用各自单位的
绝对限。混合自由度按分量保留 N 与 N·m 的区分，不把两者折叠成一种量。

跨实现比较物理观测时，旋转不逐元素比较：九个元素差不合成有意义的姿态误差。矩阵元素
只作传输，由判定方把完整旋转作为 SO(3) 元素检查和比较。位姿组合的代数单测是另一类
契约：它直接逐元素验证矩阵乘法定义，并使用表示精度量级的界限。

## 跨进程比较

参考发射器只产出观测名称与原始数值；物理量类别、必需观测集合与容差判决由判定方独占。
若两侧各自声明验收规则，共享同一个错误规则的两侧就能互相背书。

Drake 是迁移期的比较参照，不是本项目交付物的依赖，因此
`ORVD_BUILD_DRAKE_REFERENCE_TESTS` 默认关闭。开启需用 `drake-reference` 预设，Drake
位置由标准 `CMAKE_PREFIX_PATH` 提供，仓库不写入任何机器路径：

```bash
cmake --preset drake-reference -DCMAKE_PREFIX_PATH=<drake 安装前缀>
cmake --build --preset drake-reference
ctest --preset drake-reference --output-on-failure
```

台架先用同一 Drake 参考实现的两个独立进程证明管道、解析与裁判可用，并确认注入的扰动会
被发现；这一步本身不构成候选结论。G31–G32 已接入独立的 ORVD 运动学候选端，随后用能力具名
的必需观测集合分别覆盖位置与空间运动学并与 Drake 比较；启动器拒绝把同一个可执行文件同时
充当参考端和候选端。

空间速度的长期解析测试不从另一条被测查询制造期望值，而是直接使用刚体关系、点移公式和坐标
变换计算。跨进程比较另行覆盖所有场景刚体的角速度与刚体原点平移速度、具名的三坐标系相对
速度以及速度状态回读。内部缓存测试用提交重算次数区分「被标为过期」与「查询时真的重算」。

## 参考缓存语义

缓存失效语义探针在钉死的 Drake 上实测运动学缓存行为：重复求值不重算；改 `q` 或改 `v`
都使位置与速度缓存共同过期——Drake 当前只能整段取用可变 `q/v`，共同失效是参考实现的
保守现状，不是 ORVD 的要求；过期条目按需分别重算，序号只在真的重算时增长；Context
之间彼此隔离。序号只判「不变」或「严格递增」，不锁定绝对值或恰好加一。

## 位姿组合契约

四个位姿组合函数由 ORVD 自研以满足 vendored 声明，因此它们的正确性没有上游实现兜底。
`math/verify_double_pose_composition_contract` 链接**真实符号**
`drake::math::internal::Compose*`，逐一检查四条定义式，并覆盖声明允许的四种输出重叠形态：
输出独立、输出别名第一个输入、输出别名第二个输入、三个实参同为一个对象。

期望值一律先用裸 Eigen 按定义算出，且在调用之前算出——输出别名输入的调用会覆盖掉本该
读取期望值的那份数据。期望值刻意不经 `RotationMatrix::operator*`、
`RigidTransform::operator*` 或 `InvertAndCompose`：那些会绕回被测符号，实现与期望便会
按构造相符，测试也就什么都证明不了。

该测试的容差不是本项目的 `1e-8` 跨实现口径。那个口径用于比较条件良好的 `double` 物理量；这里是同一代数
恒等式在同一算术下的两种算法，诚实的界是表示精度自身的小倍数，按参与量级缩放。

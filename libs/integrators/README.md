# libs/integrators

**职责**：时间推进。抽象推进器接口与 CVODE 后端（[ADR-0003](../../docs/adr/0003-abstract-advancer-cvode-first.md)）。

**对应 Goal**：G43–G45。

CVODE 是首个也是当前唯一的后端。事务语义是这一层的核心义务：被拒绝的步不得污染
已接受的状态，被接受的步恰好提交一次。

G43 已落下动态连续状态 RHS、逐分量绝对容差值与极窄的抽象推进器接口。当前
`SystemRhsBridge` 独占一个预先配置的试算上下文；它不保存已接受上下文，RHS 因而没有可写
回接受态的路径。系统连续向量按冻结范围直接映射 `[q; v]`，不编码 GZ18 的 107 或任何车型
布局。当前桥的构造要求显式写出 `NoCallTimeAppliedForces`；模型重力、阻尼和内部力元仍参与，
但 G42 的三类调用期外力不会被假装已经接线。SUNDIALS 头与库尚未进入目标；G44 才把
`N_Vector` 的连续存储映射到该接口。

当前组装图是自治且只有多体 q/v。RHS 保留数值后端传来的时间参数，但当前计划不读取它；
额外连续状态块与事件在真实消费者进入相应 Goal 时扩展，不以注册表或空回调预占接口。

`include/orvd/integrators/` 为公开头，`src/` 为实现。SUNDIALS 为外置第三方。

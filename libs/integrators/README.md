# libs/integrators

**职责**：时间推进。抽象推进器接口与 CVODE 后端（[ADR-0003](../../docs/adr/0003-abstract-advancer-cvode-first.md)）。

**对应 Goal**：G43–G45。

CVODE 是已选定的首个且当前唯一准入后端。事务语义是这一层的核心义务：失败的公开推进不得
污染已接受的状态，成功到达边界后恰好提交一次；CVODE 内部的自适应拒步不等同于公开推进失败。

G43 已落下动态连续状态 RHS、逐分量绝对容差值与极窄的抽象推进器接口。G44 已实现真实 CVODE
后端：`double + int32`、串行向量、BDF、稠密数值 Jacobian，并完成端点复制、最近成功内步
密集输出与显式“时间 + 完整状态”重初始化；接口仍不持有系统上下文，也不暴露后端内部存储。
当前 `SystemRhsBridge` 独占一个预先配置的试算上下文；它不保存已接受上下文，RHS 因而没有可写
回接受态的路径。系统连续向量按冻结范围直接映射 `[q; v]`，不编码 GZ18 的 107 或任何车型
布局。当前桥的构造要求显式写出 `NoCallTimeAppliedForces`；模型重力、阻尼和内部力元仍参与，
但 G42 的三类调用期外力不会被假装已经接线。SUNDIALS 头只存在于私有实现，公共头不出现
任何 SUNDIALS 类型；开发期从外部前缀精确查找 7.7.0，缺失即配置失败。

当前组装图是自治且只有多体 q/v。RHS 把后端试算时间和完整状态一起写入专用试算上下文，
当前计划尚不读取时间。G45 的 `SystemContinuousStateAdvancer` 私有组合该桥与 CVODE：内部
试算从不到达接受上下文，成功边界只提交一次；失败后必须从仍有效的接受端点显式同步。同步
只复制当前确有公共写入口的关节阻尼，不建立参数袋，也不在 RHS 热路径扫描状态或参数。

额外连续状态块与事件在 G46 后的真实消费者路书中扩展，不以注册表或空回调预占接口。系统层
当前不为无人消费的密集输出增加薄转发；事件的 `x⁻→x⁺` 与发布时序继续由 ADR-0003 冻结。

`include/orvd/integrators/` 为公开头，`src/` 为实现；G46 将目标安装并导出为
`ORVD::integrators`。SUNDIALS 仍是外置第三方接口依赖，但离线源码包提供锁定源码并用同一
工具链静态构建，不把其类型带入 ORVD 公共头。

# libs/forces

**职责**：第一方动力学中的具名力输入与力元语义。

**对应 Goal**：G35–G36（逆动力学中的力元贡献、外力映射与前向动力学）。

G35 的首版准入范围仅为均匀重力，以及转动/移动关节的显式阻尼。vendored 树中已经存在的
弹簧和衬套不会因此自动成为产品能力；需要它们时须另作明确裁决。

G36 的调用期外力使用具名刚体、体固施力点、表达坐标系及关于该点取矩的空间 wrench，并按
关节种类区分 N·m 转动力矩和 N 移动力。不会提供匿名六维向量、无量纲广义力数组、持久外力
容器或旧格式兼容层。

`include/orvd/forces/` 为公开头，`src/` 为实现。

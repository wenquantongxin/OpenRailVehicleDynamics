# forces

本模块提供具名外力、车辆力元、轮轨接触力与独立车轮驱动力矩。

体扳手以受力刚体、体固作用点、表达坐标系、关于作用点的力矩和力表示。关节广义力按转动副
与移动副分别使用 N·m 和 N。均匀重力及关节阻尼由多体模型计算。

## 车辆力元

| 力元 | 本构与状态 |
|---|---|
| 三向平动弹簧—阻尼 | 参考架内的位移、位移导数与名义力 |
| 侧滚弹簧—阻尼力偶 | 相对姿态矩阵元与物理相对角速度 |
| 定轴串联弹簧—黏性阻尼 | 指定参考轴上的力状态，单位 N |
| 点对点串联弹簧—双斜率阻尼 | 沿两安装点连线的拉力状态，单位 N |
| 奇对称饱和折线阻尼 | 指定参考轴上的速度与力 |
| 参考架线性衬套 | 三向平动弹性、平动阻尼与物理角速度阻尼 |

`VehicleForcePlan` 持有模型绑定的端点、名称和本构常数。名称在装配时解析为强类型索引；
求值时读取当前相对运动与内部状态，写出成对扳手及状态导数。状态、名义力和求值暂存由运行上下文持有。

公式、符号与功率推导见[力元理论](../../docs/models_and_algorithms/force_elements/FORCE_ELEMENT_KINEMATICS_AND_WRENCHES.md)。

## 轮轨与驱动观测

`WheelRailContactForcePlan` 给出逐接触斑的纵横向力与无量纲蠕滑率，均来自产生该斑力的同次求值。
逐斑磨耗数可按 `|Tx * gamma_x| + |Ty * gamma_y|` 计算后求和。

`IndependentWheelActiveTorquePlan` 将保持转矩施加为车轮与指定反作用刚体上的等大反向力偶。

公共头位于 `include/orvd/forces/`，实现位于 `src/`。

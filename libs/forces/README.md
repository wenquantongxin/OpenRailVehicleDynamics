# libs/forces

**职责**：第一方动力学中的具名力输入与力元语义。

**对应 Goal**：G35–G36、G50、G65。

G35 的首版准入范围仅为均匀重力，以及转动/移动关节的显式阻尼。vendored 树中已经存在的
弹簧和衬套不会因此自动成为产品能力；需要它们时须另作明确裁决。

G36 的调用期外力使用具名刚体、体固施力点、表达坐标系及关于该点取矩的空间 wrench，并按
关节种类区分 N·m 转动力矩和 N 移动力。不会提供匿名六维向量、无量纲广义力数组、持久外力
容器或旧格式兼容层。

G50 增加四类真实车辆力元：代数平动弹簧—阻尼、侧滚纯力偶、带一维力状态的串联弹簧—黏性
阻尼、奇对称限幅阻尼。`VehicleForcePlan` 冻结力元名称、模型坐标系与本构常数；名称只用于启动期
解析强类型槽。端点的唯一身份是模型坐标系，载荷刚体与体固落点在当前上下文中由多体模型解析，
不从可变车型记录重建第二份身份。计划本身只读，扳手、状态导数与其他暂存均归运行时上下文。

G65 增加 `HalfAngleMidpointRollPitchYawBushing`：以两端姿态构造半角中间坐标系，在两体瞬时
重合的共同中点施加三向平动与三向转动刚阻扳手。它不复用平动力元的真实端点与参考端支承矩
公式，也不额外增加支承矩；四组刚阻常数由不可变 `VehicleForcePlan` 持有，不增加连续状态、
预载或运行时语义开关。

`WheelRailContactForcePlan` 的公共逐接触斑观测同时给出接触坐标系内的纵/横向力与无量纲纵/横向
蠕滑率。蠕滑率直接搬运产生该斑力的同一次 `WheelRailContactPatchResult`，不在力计划中重算，也
不暴露自旋蠕滑率；消费者可按同一 patch 形成 `|Tx * gamma_x| + |Ty * gamma_y|`。

`include/orvd/forces/` 为公开头，`src/` 为实现。

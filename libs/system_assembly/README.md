# libs/system_assembly

**职责**：模型中立的系统组装层。

把多体运行时、力元与推进器组装成一个可推进的整体，接口不含任何车辆概念。

**对应 Goal**：G40–G43、G45。

G40 已落下不可变的 `SystemAssemblyDescription`。当前描述一个已最终化的多体组件和可选的
类型化车辆力元计划：q/v 与力元内部 z 状态块、组件上下文内的类型化物理参数，以及唯一的
`[qdot; vdot; zdot]` 输出。描述借用模型与力元计划，但不创建上下文、工作区或输入值。

未准入的能力在编译期不存在。不设端口注册表、字符串查找、通用参数袋、车型规则、占位或
兼容入口；一个“暂时什么也不做”的接口，与一个已实现的接口在调用点上无法区分。

G41 的 `SystemInstance` 把 q/v/z 布局、组件索引与真实消费者需要的具名力元槽冻结为强类型值；
它没有追加入口。每个 `SystemRuntimeContext` 唯一拥有一份 `MultibodyEvaluationContext` 与
力元 z 状态，不另建 q/v 副本；同一上下文还一次创建模型绑定的前向动力学工作区和力元暂存。
名称只在启动装配时解析一次，右端热路径只使用冻结序号。

上下文局部的转动/移动关节阻尼通过各自物理单位的窄入口写入原有无版本参数。阻尼力在下一次
调用时直接读取新值；不为没有长期缓存消费者的量制造版本源。

G43 在该冻结布局上增加连续存储双向映射。输出按 `[q; v; z]` 读取唯一状态，输入通过模型
感知的完整 q/v 事务与定长 z 写回；不建立供推进器长期持有的第二份物理状态。事务在写前完成
尺寸、有限性与四元数检查，任一失败均不留下半写状态。

G45 让根运行时上下文持有有限的已接受时间，并增加“时间 + 完整 `[q;v;z]`”唯一接受事务。
全部校验先完成，q/v/z 写入成功后才赋时间；拒绝不会留下新时间与旧状态的组合。同一时刻的
外部状态或上下文局部物理参数写入后，由系统推进器显式同步试算上下文与数值后端。

G42 的 `CompiledSystemPlan` 把当前准入图编成唯一且直接的顺序：每个冻结车辆力元恰好求值一次，
扳手在既有多体入口中装配，随后恰好求值一次 `[qdot; vdot; zdot]`。它复用组件上下文的版本缓存
与工作区，不建立第二张依赖图。成功或失败的导数试算均不写已接受状态。

当前准入图没有产生事件的组件，因此初始化更新、周期更新和周期发布三张计划均为空，公共 API
中也不存在通用事件、witness、逐步事件、监视器、forced event 或通用离散更新占位。第一位
真实事件消费者出现时必须按 ADR-0003 的已裁决语义编译封闭计划；不以空回调提前占接口。

`include/orvd/system_assembly/` 为公开头，`src/` 为实现。

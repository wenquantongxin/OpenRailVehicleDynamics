# libs/system_assembly

**职责**：模型中立的系统组装层。

把多体运行时、力元与推进器组装成一个可推进的整体，接口不含任何车辆概念。

**对应 Goal**：G40–G42。

G40 已落下不可变的 `SystemAssemblyDescription`。首版只描述一个已最终化的多体组件：
q/v 两个连续状态块、组件上下文内的类型化物理参数、具名刚体 wrench/转动力矩/移动力输入，
以及唯一的 `[qdot; vdot]` 输出。描述借用模型但不创建上下文、工作区或输入值。

未准入的能力在编译期不存在。不设端口注册表、字符串查找、通用参数袋、车型规则、占位或
兼容入口；一个“暂时什么也不做”的接口，与一个已实现的接口在调用点上无法区分。

G41 的 `SystemInstance` 把 q/v 范围和组件索引冻结为强类型值；它没有追加入口。具名
`SystemRuntimeContext` 唯一拥有一份 `MultibodyEvaluationContext`，G21 状态位于其中且不
另建 q/v 副本；同一上下文还一次创建模型绑定的前向动力学工作区。组件视图只借用模型、
上下文和工作区，不复制计算接口，也不按名称在热路径查找。

上下文局部的转动/移动关节阻尼通过各自物理单位的窄入口写入原有无版本参数。阻尼力在下一次
调用时直接读取新值；不为没有长期缓存消费者的量制造版本源。

G42 的 `CompiledSystemPlan` 把当前准入图编成唯一且直接的顺序：三类具名力在既有多体入口中
装配，随后恰好求值一次 `[qdot; vdot]`。它复用组件上下文的版本缓存和 G41 工作区，不建立
第二张依赖图，也不为静态顺序预热无人请求的缓存。成功或失败的导数试算均不写已接受 q/v。

当前准入图没有产生事件的组件，因此初始化更新、周期更新和周期发布三张计划均为空，公共 API
中也不存在通用事件、witness、逐步事件、监视器、forced event 或通用离散更新占位。第一位
真实事件消费者出现时必须按 ADR-0003 的已裁决语义编译封闭计划；不以空回调提前占接口。

`include/orvd/system_assembly/` 为公开头，`src/` 为实现。

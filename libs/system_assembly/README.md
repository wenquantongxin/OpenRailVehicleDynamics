# system_assembly

本模块将多体模型、车辆力元、轮轨接触及主动转矩组装为连续动力学系统。

## 模型与上下文

`SystemAssemblyDescription` 借用已最终化的多体模型和力元计划。
`SystemInstance` 确定状态布局、组件索引及具名力元槽位；状态维数由所装配模型决定。

`SystemRuntimeContext` 持有多体状态、串联内力、已接受时间、接触投影历史、物理参数和求值暂存。
名称在装配阶段解析，右端求值使用固定索引。

## 连续状态与接受态

连续状态按 `[q;v;z]` 排列。两类串联元件的内力共同组成 `z`，每个元件占一个 N 单位分量。
名义力、关节阻尼和保持转矩作为上下文参数单独存储。

状态读取形成连续数组；写入前校验尺寸、有限性和四元数。
时间与完整状态共同提交。成功内部端点更新接触投影历史，试算使用独立上下文。
接受态或上下文参数发生外部更新后，系统推进器同步试算上下文与数值后端。

## 右端求值

`CompiledSystemPlan` 按车辆力、轮轨力和主动转矩的固定切片组装体扳手，
调用多体前向动力学，并与内力导数组成 `[qdot;vdot;zdot]`。
导数求值使用上下文已有工作区，保持已接受状态。

公共头位于 `include/orvd/system_assembly/`，实现位于 `src/`。

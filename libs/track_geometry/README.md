# track_geometry

线路层：轨道惯性系、沿线路铺开的标量剖面、由它们导出的坐标系，以及空间点到中心线的站位投影。
本模块不知道多体、接触与积分器；依赖方向是它们朝这里，而不是反过来。

## 坐标约定

惯性系 `I` 固定在线路上，不固定在地球上。原点是线路起点，`+x` 指向该处里程增加的方向，
`+y` 指向面向里程增加方向时的右侧，`+z` 向下。该系为右手系，所以重力沿 `+z`，
绕 `+z` 的正转把航向从 `+x` 转向 `+y`——**正曲率是右转弯**。

两个坐标系沿线路移动。**无侧滚切向系**的 `x` 轴沿三维中心线的单位切向，`y` 轴水平且指向轨道
右侧，`z` 轴补成右手三元组。**轨型系 `T`** 是无侧滚系绕其自身 `x` 轴滚转一个由超高决定的角度后
得到的，它才是钢轨与车辆看到的那个系。

有符号超高不是惯性系竖向高差，而是
`(p_right − p_left) · z_T0`：沿无侧滚系竖轴度量的两轨高差。只有纵坡为零时二者相等；一般情形
惯性系竖向高差还要除以 `sqrt(1 + grade²)`。这一定义使侧滚角保持为
`asin(superelevation / reference_span)`。

多体底座保持坐标中立。本模块不给任何模型设置重力；`GravitationalAccelerationInInertial`
只声明线路层所说的「下」是哪个方向，装配器必须显式安装它。

## 站位是平面投影里程

自变量 `track_station` 是**平面投影里程**，不是三维弧长。两个后果贯穿全模块：

- 中心线导数的水平投影是单位向量，而完整三维导数的模是 `sqrt(1 + grade²)`；
- 纵坡 `centerline_upward_grade` 无量纲、沿里程增加方向上坡为正，因此由于 `+z` 向下，
  `d(中心线 z)/d(track_station) = −centerline_upward_grade`。

## 缓和曲线不是回旋线

缓和段是曲率的 **Hermite 三次混合** `3x² − 2x³`：两端曲率一阶导为零、二阶导跳变。
回旋线的曲率随里程线性变化、两端曲率一阶导非零，二者不是同一条线形。
下游不得按外部回旋线标准验收本模块的缓和段。

因为端点一阶导恒为零，「端点一阶导连续」在本形状下是 `0 = 0`，不足以把 Hermite 三次与其他
混合形状区分开。真正钉住这个身份的是内部点值 `κ(L/4) = κ₁ + (5/32)·Δκ`。

## 接缝过渡是声明的几何区间

相邻段可以声明一段接缝过渡：窗口以两段的公共边界为中心、长度显式给定，窗口内取匹配两端值、一阶导与二阶导的五次多项式。它是几何的一部分，**不是构造后对段的静默改写**；任何关于某段自身取值的陈述，只适用于该段落在声明窗口之外的部分。窗口重叠、越过相邻段或参数非法时在构造期拒绝。

接缝由**前一段的序号**指认，不由写出来的边界站位指认。边界站位是各段长度累加出来的，调用方另行算出的同一个数不必与它逐位相同，用浮点相等去匹配会在无关处失败。同一段上声明两次接缝也在构造期拒绝。

**没有声明接缝的相邻边界必须连续**：三族剖面在该处的声明端值必须完全相同。值一旦跳变，建立在其上的一阶运动学在该站位就不存在，而求值路径将不得不为一个不存在的量返回一个数。要表达「直线直接接圆曲线」这种理想化，就显式声明一段过渡窗口。

## 求积与容差

直线段与圆曲线段解析积分。Hermite 缓和段或接缝窗口使全局航向成为多项式，其正余弦没有初等
原函数，所以构造时按固定阶 Gauss–Legendre 规则、以不超过节点间距的分块预计算节点位置。
非节点站位求值时最多再积该节点内的一个部分分块；精度由声明的节点间距决定，而不是由调用方
临时决定。本模块不把“任意正间距都达到同一误差界”写成并不存在的保证。

因此本模块的验收容差分三档，互不冒充：解析段用机器精度的小倍数；数值求积段按阶数、
区间长度与误差估计单列预算；用中心差分反算的量按有限差分预算。

## 分配纪律

构造期允许分配。**求值期不允许**：在返回结果的那条路径上，不构造也不扩容动态容器，不做
名称查询，不格式化字符串，不写日志，不访问文件。节点表与求积系数由不可变的几何对象预先
持有。

这条纪律约束的是成功返回的路径。拒绝路径要抛异常，异常必须说清楚被拒的是哪个数，所以它
会格式化字符串并分配。这不构成例外：拒绝路径不返回结果，右端热路径上凡是能返回结果的求
值都不会走到那里；把诊断信息削成常量以求纪律统一，换来的是一条查不出原因的失败。

## 域是合同

站位定义域是显式合同。域外求值显式失败，既不外推也不夹取。三族剖面必须覆盖同一段线路，
但各自的终点站位是各自段长度的累加，同一个总长按不同的分段方式累加不必落到同一个
binary64 数上，所以终点只要求相符到累加本身的可表示分辨率——按各族的加法次数定界。逐位
相等会把「覆盖同一段线路」变成「以同样的方式写下来」。容差尺度同时包含线路起点；否则大
负起点与正段长几乎相消时，终点虽接近零，累加却始终发生在大站位量级。通过后，三族终点规
范到其中最短的可表示终点，保证任何公共终点求值都不靠外推。

节点间距只是有限且为正还不够：极小的间距会要求一张任何机器都放不下的节点表，而节点数还
要转成无符号整数，一旦超出 double 的可转换范围就是未定义行为。因此**整条线路**的节点总数
在构造期上限为 2^20；它仍容纳 10 km 线路约 1 cm 的节点间距，同时把意外的巨型分配挡在转换
和分配之前。越界即拒绝并要求给出更粗的间距。超高绝对值达到或超过轨距参考
横向跨距时在构造期拒绝，而不是裁剪——裁剪会把一个建模错误变成一条看起来合理的线路。

## 投影

投影原语不保存任何历史，也**不做全线搜索**。求任意点的最近站位意味着枚举整条线路上目标函数的全部极小值，而没有任何廉价的构造期界能保证这个枚举：一条在平面上笔直、只在纵断面上起伏的线路，可以在一个节点区间内放下两个与该点等距的极小值；一条曲率对称摆动的线路，可以让航向在区间两端毫无变化而在区间内部扫过好几个弧度。与其承诺一个证不出来的搜索，不如让初始站位由调用方给出——已解析启动状态携带它，接受步推进它。

本原语承诺的正是受括搜索能给的：在调用方声明的区间内、严格位于区间内部的那个极小根。判据用通式

```
objective   = ½ |point − centerline|²
objective'  = −(point − centerline) · centerline'
objective'' = |centerline'|² − (point − centerline) · centerline''
```

并要求一阶导满足残差门、二阶导严格为正。区间内无可容许极小根、有两个与种子等距的极小根、或极小根落在窗口壁上，三者都显式失败——最后一种说明窗口放错了位置，而不是分支没找到。

一个区间内的两个驻点由节点网格分开，或者根本分不开，所以搜索的分辨力是所声明的节点间距的性质，不是本合同能单独承诺的东西。调用方必须给出能隔离所跟踪分支的种子、局部窗口与几何分辨率；藏在同一个节点区间里的多个驻点不属于本原语的完备性承诺。窗口短并不能单独证明该前提成立。

在上述前提下，每个由节点子区间括住的极小根都会用受括 Newton—二分细化，最后返回站位上最靠近种子的候选；若最近的两个候选与种子等距，则显式失败。

「等距」按两个尺度里较大的那个判定：调用方声明的搜索半宽，以及两根定位误差与三次站位差
运算的数值预算。前者是调用方给出的意义尺度——在一个只有半毫米宽的窗口里，相差半宽十亿
分之一的两个候选不可能是调用方想区分的东西；后者显式合计受括停止误差、共享节点规范化误
差和站位算术 ULP——站位是绝对里程，在很大的站位原点上，两个几乎相等的间距的末几位只是
噪声，单按窗口宽度判定会把噪声读成真实次序并据此挑一条分支。两个尺度取大，等价于分别判
断后取逻辑或；把它们相加反而会无依据地扩大模糊区。以米为单位的固定下限两个尺度都不是。

想要预测种子的消费者自己算预测值再传进来；本层不接收站位变化率或步长，因为它无从分辨接受步与试算步。

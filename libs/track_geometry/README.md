# track_geometry

线路层：轨道惯性系、沿线路铺开的标量剖面、由它们导出的坐标系，以及空间点到中心线的站位投影。
本模块不知道多体、接触与积分器；依赖方向是它们朝这里，而不是反过来。

## 坐标约定

惯性系 `I` 固定在线路上，不固定在地球上。原点是线路起点，`+x` 指向该处里程增加的方向，
`+y` 指向面向里程增加方向时的右侧，`+z` 向下。该系为右手系，所以重力沿 `+z`，
绕 `+z` 的正转把航向从 `+x` 转向 `+y`——**正曲率是右转弯**。

两个坐标系沿线路移动。**无侧滚切向系**的 `x` 轴沿三维中心线的单位切向，`y` 轴水平且指向轨道
右侧，`z` 轴补成右手三元组。**轨型系 `T`** 是无侧滚系绕其自身 `x` 轴滚转一个由超高决定的角度后
得到的，它才是钢轨与车辆看到的那个系。

有符号超高不是惯性系竖向高差，而是
`(p_right − p_left) · z_T0`：沿无侧滚系竖轴度量的两轨高差。只有纵坡为零时二者相等；一般情形
惯性系竖向高差还要除以 `sqrt(1 + grade²)`。这一定义使侧滚角保持为
`asin(superelevation / reference_span)`。

多体底座保持坐标中立。本模块不给任何模型设置重力；`GravitationalAccelerationInInertial`
只声明线路层所说的「下」是哪个方向，装配器必须显式安装它。

## 站位是平面投影里程

自变量 `track_station` 是**平面投影里程**，不是三维弧长。两个后果贯穿全模块：

- 中心线导数的水平投影是单位向量，而完整三维导数的模是 `sqrt(1 + grade²)`；
- 纵坡 `centerline_upward_grade` 无量纲、沿里程增加方向上坡为正，因此由于 `+z` 向下，
  `d(中心线 z)/d(track_station) = −centerline_upward_grade`。

## 缓和曲线不是回旋线

缓和段是曲率的 **Hermite 三次混合** `3x² − 2x³`：两端曲率一阶导为零、二阶导跳变。
回旋线的曲率随里程线性变化、两端曲率一阶导非零，二者不是同一条线形。
下游不得按回旋线标准解释本模块的缓和段。

## 接缝过渡是声明的几何区间

相邻段可声明一段以公共边界为中心的五次过渡，在窗口两端匹配值、一阶导与二阶导。接缝由
前一段序号指认；窗口重叠、越过相邻段或参数非法时构造失败。没有接缝的相邻段必须端值连续，
否则该边界的一阶运动学不存在。

## 求积与容差

直线与圆曲线解析积分；缓和段和接缝用固定阶 Gauss–Legendre 求积，并按声明的节点间距预计算。
非节点求值最多补积一个节点区间。解析式、数值求积和有限差分分别使用与其算法相符的误差预算。

## 分配纪律

构造期允许分配。成功求值路径不扩容动态容器、不查名称、不写日志、不访问文件；拒绝路径可为
异常诊断分配。节点表与求积系数由不可变几何对象持有。

## 基础轨道定义区间与原生延长

曲率、超高和纵坡必须覆盖同一有限定义区间；因不同分段顺序会产生末位舍入差，终点按累加次数
给出紧容差并规范到共同终点。该定义区间仍可经 `ClassifyTrackStation()` 观察。对区间外的任意
有限站位，线路从最近定义边界沿三维切线作直线延长：航向、纵坡和超高保持边界值，曲率及
三者的站位变化率为零。当前 `[0,2000] m` 随包线路因此在左右两侧都原生延长为直线、水平、
零超高线路，无需给 JSON 人工补负站位或远端空白段。非有限站位仍被拒绝。

整条定义区间最多预计算 `2^20` 个节点，超限时要求增大节点间距。超高绝对值达到参考横向跨距时
拒绝，不做裁剪。

## 投影

投影是无历史的**局部分支跟踪**，不做全线最近点搜索。调用方提供种子和有限局部窗口；窗口可以
位于定义区间内、任一侧直线延长上，或横跨定义边界，并且不会被夹取到定义区间。窗口在声明的节点
分辨率下必须恰有一个严格位于窗口内部的合格极小根。判据为

```
objective   = ½ |point − centerline|²
objective'  = −(point − centerline) · centerline'
objective'' = |centerline'|² − (point − centerline) · centerline''
```

根由受括 Newton—二分细化，并须满足一阶导残差门和 `objective'' > 0`。窗口壁上的根不计入候选；
没有唯一严格内点根时失败。同一节点区间内未被网格分开的多根不在完备性承诺内。预测种子由上层
计算，本层不接收站位变化率或步长。
